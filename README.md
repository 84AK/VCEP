# VCEP (VibeCoding Expert Program)

VCEP는 AI와 함께 협업하여 앱을 기획하고 개발하는 '바이브코딩(VibeCoding)'을 마스터하기 위한 교육용 시뮬레이션 플랫폼입니다.

## 🚀 주요 기능
- **Space Logic Center**: 팀 단위로 진행하는 고퀄리티 앱 기획 시뮬레이터.
- **VibeCoding Training Hub**: AI 인턴 '에이든'과 함께 실전 코딩 이슈를 해결하는 트레이닝 센터.
- **App Planner**: 체계적인 PRD 작성을 돕는 로직 캔버스.

## 📚 학습 가이드
모든 앱은 `apps/` 폴더 내에 위치하며, 브라우저에서 직접 실행 가능합니다.
