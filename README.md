# 🌟 VibeCoding Expert Practice: Iron-Wall AI Dating Sim

본 프로젝트는 프롬프트 엔지니어링의 핵심 기술들을 연애 시뮬레이션 형식을 통해 재미있고 직관적으로 배울 수 있는 인터랙티브 교육 플랫폼입니다.

## 🚀 주요 기능 (Key Features)

- **Interactive Dialogue**: 비주얼 노벨 방식의 순차적 대화 시스템으로 몰입감 있는 스토리 전개.
- **Prompt Engineering Practice**: 
  - **RCTF**: 캐릭터의 정체성(Role, Context, Task, Format) 주입.
  - **Few-shot**: 예시 데이터를 통한 패턴 학습.
  - **Temperature**: 감정의 온도를 조절하여 답변의 감성 수치 제어.
  - **Negative Prompt**: 금기어 설정을 통한 답변 품질 최적화.
- **Mastery Report**: 각 단계 완료 후 제공되는 모범 프롬프트 예시와 실력 성적표.
- **Dynamic Ending**: 플레이어의 선택과 프롬프트 능력에 따른 멀티 엔딩 시스템.

## 🛠 기술 스택 (Tech Stack)

- **Frontend**: HTML5, Vanilla CSS, JavaScript
- **Animation**: Anime.js, CSS Keyframes
- **Design**: Glassmorphism 2.0, Bento Grid Layout
