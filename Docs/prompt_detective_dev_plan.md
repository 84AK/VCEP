# Prompt Detective — 개발 작업 계획서

> 파일 경로: `apps/03_expert/prompt_detective.html`  
> 목표: 프롬프트 엔지니어링 5가지 핵심 기법을 추리게임 형식으로 학습하는 인터랙티브 게임

---

## 게임 학습 구조 (5 Stage)

| Stage | 기법 | 게임 서사 |
|-------|------|---------|
| 1 | RCTF (Role/Context/Task/Format) | 탐정 프로필 설계 |
| 2 | Few-shot 프롬프팅 | 심문 단서 통합 |
| 3 | Temperature | 추리 감도 설정 |
| 4 | Negative Prompting | 편향 차단 필터 |
| 5 | Chain-of-Thought | 사고 사슬 구성 |

---

## ✅ 완료된 작업

### Phase 1 — 게임 기반 UX 수정
- [x] `alert()` 5곳 전부 제거 → 인게임 토스트(Toast) 시스템으로 교체
- [x] 대화창 화자 레이블 추가 (수사관: 초록, 용의자: 주황 색상 구분)
- [x] 퀴즈 오답 처리 개선 — `alert` 제거, 모달 내 힌트 패널로 교체 (왜 틀렸는지 설명 포함)
- [x] 심문 완료 뱃지 — 심문한 용의자 카드에 "✓ 심문 완료" 오버레이 표시
- [x] 범인 지목 결과 — `alert("성공!")` 제거, 성공/실패 전용 모달로 교체
- [x] 스테이지 전환 시 어두운 오버레이 추가 (배경 이미지/대화창과 겹침 방지)
- [x] 액션 패널 레이아웃 수정 — `left/right` 방식으로 프롬프트 빌더와 겹침 해결

- [x] 액션 패널 내 "AI 탐정 미리보기" 섹션 추가
- [x] Stage 1 (RCTF): Role 입력 전/후 비교
- [x] Stage 2 (Few-shot): 예시 0개 vs 3개 비교 패널
- [x] Stage 3 (Temperature): 슬라이더 움직일 때마다 실시간 출력 스타일 변화
- [x] Stage 4 (Negative): 필터 없을 때의 편향된 답변 vs 필터 적용 후 비교
- [x] Stage 5 (CoT): 단계 없이 vs 단계적 사고 출력 비교

### Learning Layer 3 — 프롬프트 누적 빌더
