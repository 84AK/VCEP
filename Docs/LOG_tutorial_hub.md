# 작업 로그: 튜토리얼 허브 업데이트 (02_mental 앱)
**날짜:** 2026-05-11
**담당:** 작업자(Worker) & 서기(Doc)

## 1. 작업 개요
- **목적:** `apps/02_mental` 폴더에 위치한 감정·정신건강 관련 앱들의 기획서/프롬프트/해결책 가이드(학습 가이드)를 `apps/tutorial_hub.html` 페이지에 신규 추가함.
- **대상 파일:** `apps/tutorial_hub.html`

## 2. 주요 구현 내용
### 2.1. 신규 섹션 추가
- 기존 "나만의 웰니스 앱 만들기" 섹션 아래에 **"마음의 위로, 정신건강 앱 만들기"**라는 새로운 섹션을 추가하고, 해당 섹션의 카드 그리드를 신설함.

### 2.2. 9개 정신건강 앱 카드 및 가이드 데이터 추가
기존 01_wellness 테마와 동일한 방식으로, 02_mental 폴더 내 9가지 앱에 대한 가이드(모달 콘텐츠) 데이터를 추가 구성함.

1. **🌊 심해의 파동 (fluid):** 발광 유체를 사용한 감정 시각화
2. **✈️ 응원의 종이비행기 (airplane):** 종이비행기로 위로 전하기
3. **💬 마음의 온도 (dialogue):** 선택지에 따라 바뀌는 공감 온도
4. **📮 다정한 마음 배달부 (postman):** 익명 칭찬 우체통
5. **🗼 마음의 등대 (lighthouse):** 동화 텍스트 기반의 대처 가이드
6. **🏮 기억의 등불 (lantern):** 풍등 애니메이션을 통한 미련 비우기
7. **🗺️ 마음 쉼터 지도 (map):** 지역별 정신건강 자원 안내 마커
8. **🔥 비밀 잉크와 불꽃 (fire):** 부정적 감정을 불꽃에 태우는 리추얼
9. **🌷 마음 정원 (garden):** 청소년들의 감정을 꽃으로 표현하는 정원

### 2.3. 각 가이드별 데이터 구성 (JSON)
- `planning`: 문제 정의, 사용자 정의, 기능 설계, 화면 구성 단계 (앱 플래너 양식과 동일)
- `prompt`: 각 앱에 맞춘 Gemini 시니어 개발자 프롬프트 (Canvas API, Web Audio, Leaflet 등 맞춤형 기술 요구 포함)
- `troubles` 및 `ideas`: 모달에 표시될 1문 1답 예상 오류 대처법과 추가 발전 방향 아이디어 기록

## 3. 발생 문제 및 해결
- **이전 문제:** `tutorial_hub.html`은 단일 파일로 스크립트 데이터 양이 많아져 가독성이 저하될 수 있었음.
- **해결 방안:** JavaScript 객체 배열에 새로운 키(`fluid`, `airplane` 등)로 명확히 분리하여 기존 로직(`openTutorial`)과 완벽히 호환되게 통합함.

### 2.4. UI/UX 섹션 구분
- 기존 앱 리스트와 신규 앱 리스트 사이에 시각적 구분선(`.section-divider`)을 추가함.
- 각 파트를 명확하게 보여주는 뱃지 디자인(`.section-badge`)을 도입하여, 'PART 1: 스마트폰 과사용 예방'과 'PART 2: 감정 및 정신건강 케어' 영역을 시각적으로 완전히 분리함.
### 2.5. 누락된 기획서 데이터 전체 복원
- 앱 플래너의 모든 입력 필드(가장 힘든 순간, 넣지 않을 기능, 화면 구성 세부, 앱 소개 등)가 02_mental 앱 9개에서 일부 생략되었던 문제를 확인하고, 이전(01_wellness)과 동일하게 100% 생략 없이 상세하게 채워넣음.
