# PRD: Logic Canvas (AI 로직 플래너)

## 1. 프로젝트 개요
개발할 앱의 구조와 로직을 시각적으로 설계하고, 설계된 내용을 구글 시트에 백업하여 언제 어디서든 설계를 이어갈 수 있도록 돕는 전문 플래닝 도구입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 코딩 시작 전 로직 설계를 체계화하고 싶은 학생 개발자
- **문제 정의**: 머릿속으로만 생각하고 코딩을 시작하면 나중에 로직이 꼬임. 설계를 문서화해야 하지만 매번 파일을 저장하고 관리하는 것이 번거로움.

## 3. 핵심 기능 (Key Features)
- **로직 블록 설계**: 앱의 주요 기능과 데이터 흐름을 블록 단위로 정의
- **프롬프트 자동 생성**: 설계된 내용을 바탕으로 AI에게 전달할 '최적의 프롬프트'를 구성해주는 기능
- **클라우드 설계 보관함**: 작성 중인 설계도를 구글 시트에 저장하고, 나중에 다시 불러와서 수정 가능
- **내보내기 기능**: 설계도를 PDF나 이미지로 저장하거나, Markdown 형식의 PRD로 변환

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Developer-Centric UI**: 깔끔한 다크 모드와 시스템 폰트를 사용하여 전문적인 느낌 강조
- **Infinite Canvas Experience**: 화면을 넓게 쓰며 자유롭게 설계할 수 있는 레이아웃
- **Action-Oriented Buttons**: 'Copy Prompt', 'Save to Cloud' 등 핵심 기능을 눈에 띄게 배치

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, Mermaid.js (Flowchart generation)
- **Backend**: Google Apps Script (GAS)
- **Database**: Google Sheets

## 6. 사용자 흐름
1. 새 프로젝트 기획 시작 -> 2. 기능 및 로직 블록 입력 -> 3. '시트 저장' 클릭 -> 4. 필요 시 '불러오기'로 수정 -> 5. 완성된 로직을 AI 프롬프트로 복사하여 개발 시작

## 7. 데이터 관리 전략
- **Structured JSON Backup**: 설계도의 전체 구조를 JSON 객체로 직렬화하여 구글 시트의 `ProjectPlan` 시트에 보관.
- **Version Control**: 저장 시점을 기준으로 버전을 관리하여 이전 설계로 되돌릴 수 있는 기능 고려.
