# PRD: AI Tarot Reader (AI 타로 운세)

## 1. 프로젝트 개요
AI가 사용자의 질문에 맞춰 타로 카드를 해석하고, 복채(운세 결과)를 구글 시트에 차곡차곡 쌓아 나만의 '운세 기록장'을 만드는 GAS 연동 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 일상의 작은 고민을 AI와 나누고 싶은 청소년 및 운세 기록을 장기적으로 보관하고 싶은 사용자
- **문제 정의**: 일회성으로 끝나는 운세 결과는 나중에 다시 찾아보기 어려움. 클라우드에 날짜별로 저장하여 트렌드를 분석하고 싶음.

## 3. 핵심 기능 (Key Features)
- **AI 카드 해석**: 랜덤으로 선택된 타로 카드와 질문을 결합하여 AI(Gemini 등) 스타일의 상담 멘트 생성
- **클라우드 로그**: 상담 일시, 선택한 카드, AI 해석 내용을 구글 시트에 실시간 저장
- **타로 캘린더**: 시트의 데이터를 기반으로 지난 며칠간 어떤 운세가 나왔는지 시각적으로 보여줌
- **연속 출석 체크**: 매일 운세를 볼 때마다 시트의 출석 카운트가 올라가는 게이미피케이션

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Mystical Glassmorphism**: 보랏빛 그라데이션과 반투명 유광 효과를 사용한 신비로운 분위기
- **Animated Cards**: 카드 선택 시 뒤집히는 3D 모션 효과
- **Night Mode Default**: 운세의 몰입감을 높이기 위한 세련된 다크 모드 UI

## 5. 기술 스택
- **Frontend**: HTML5, CSS (3D Transforms), Vanilla JS
- **Backend**: Google Apps Script (GAS)
- **Database**: Google Sheets

## 6. 사용자 흐름
1. 질문 입력 -> 2. 카드 셔플 및 선택 -> 3. AI 해석 결과 확인 -> 4. '기록하기' 버튼으로 시트 전송 -> 5. 기록 탭에서 과거 운세 히스토리 확인

## 7. 데이터 관리 전략
- **Append-Only Logging**: 기존 데이터를 수정하지 않고 새로운 운세를 계속 추가하는 방식으로 시트 로그 관리.
- **Privacy First**: 민감한 질문은 암호화하거나 사용자만 볼 수 있도록 관리 지침 안내.
