# PRD: Pixel Master Pro (픽셀 낙서장)

## 1. 프로젝트 개요
사용자가 웹 상에서 자유롭게 픽셀 아트를 그리고, 그 데이터를 구글 스프레드시트에 영구적으로 저장 및 관리할 수 있는 클라우드 기반 드로잉 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 디지털 아트를 배우고 싶은 학생 및 데이터의 클라우드 저장을 학습하려는 초급 개발자
- **문제 정의**: 로컬 브라우저에만 저장되는 데이터는 기기가 바뀌면 사라지는 한계가 있음. 이를 구글 시트를 활용한 백엔드 연동으로 해결하고자 함.

## 3. 핵심 기능 (Key Features)
- **픽셀 드로잉**: 20x20 그리드 환경에서 마우스 드래그를 통한 실시간 픽셀 드로잉 지원
- **데이터 압축 저장**: 400개의 픽셀 색상 데이터를 하나의 긴 문자열(Payload)로 압축하여 시트의 단일 셀에 효율적으로 저장
- **클라우드 로드/복원**: 구글 시트에 저장된 과거 기록 목록을 불러와 캔버스에 즉시 복원하는 기능
- **가이드 오버레이**: 초보자를 위한 '하트' 등 기본 도면 가이드 표시 기능
- **GAS 백엔드**: Google Apps Script(doPost, doGet)를 활용한 시트 연동 CRUD 로직

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Sheet-Like Aesthetics**: 구글 스프레드시트의 테마 컬러(Green)와 격자 무늬 배경을 활용한 브랜딩
- **Bento Grid Layout**: 도구함, 캔버스, 보관함을 박스 형태로 배치하여 직관적인 정보 제공
- **Real-time Feedback**: 픽셀을 칠할 때마다 즉시 시각적으로 반영되는 부드러운 반응성

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Grid & Flexbox)
- **Backend**: Google Apps Script (GAS)
- **Database**: Google Sheets
- **Protocol**: RESTful API (JSON 기반 통신)

## 6. 사용자 흐름
1. 앱 접속 -> 2. 픽셀 가이드 선택 또는 자유 드로잉 -> 3. '시트에 저장' 클릭 -> 4. 보관함 탭에서 저장된 목록 확인 -> 5. 특정 항목 '불러오기' 클릭하여 복원

## 7. 데이터 관리 전략
- **Cloud Persistence**: 모든 드로잉 데이터는 `PixelData` 시트에 저장되며, `save`, `list`, `load` 액션 파라미터를 통해 GAS와 통신함.
- **Optimization**: 픽셀 배열을 JSON 문자열로 변환하여 전송함으로써 네트워크 대역폭과 시트 용량을 최소화함.
