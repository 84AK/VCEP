# PRD: Mission Board (협업 미션 보드)

## 1. 프로젝트 개요
구글 스프레드시트를 칸반 보드처럼 활용하여, 팀원이나 개인의 할 일을 관리하고 성취도를 실시간으로 추적하는 협업 도구입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 복잡한 협업 툴 대신 익숙한 구글 시트로 업무를 관리하고 싶은 소규모 팀
- **문제 정의**: 시트 화면을 직접 수정하는 것은 실수가 생기기 쉽고 가독성이 떨어짐. 웹 UI를 통해 데이터를 입력하고 시트는 데이터베이스로만 활용하고 싶음.

## 3. 핵심 기능 (Key Features)
- **미션 카드 CRUD**: 새로운 할 일 생성, 내용 수정, 상태(To-Do, In-Progress, Done) 변경 기능
- **실시간 상태 동기화**: 한 명이 상태를 변경하면 시트에 즉시 반영되어 다른 사용자도 확인 가능
- **성취도 대시보드**: 시트의 데이터를 읽어와 전체 미션 중 완료된 비율을 그래프로 표시
- **태그 및 필터링**: 긴급도, 담당자별로 미션을 필터링하여 보기

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Bento Card Interface**: 할 일을 카드 형태로 배치하여 깔끔한 시각적 정리
- **Interactive Drag & Drop**: 카드를 드래그하여 상태를 변경하는 직관적인 UX (추후 구현)
- **High-Contrast Indicators**: 중요도에 따라 색상을 다르게 부여하여 시인성 확보

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Flexbox Grid)
- **Backend**: Google Apps Script (GAS)
- **Database**: Google Sheets

## 6. 사용자 흐름
1. 미션 목록 조회 -> 2. 새로운 미션 생성 -> 3. 미션 진행 중 상태로 변경 -> 4. 완료 후 체크 -> 5. 시트에서 전체 진행 상황 및 로그 확인

## 7. 데이터 관리 전략
- **Row-based Management**: 각 미션을 시트의 한 행(Row)으로 관리하며, `id` 값을 기준으로 특정 미션 수정/삭제 처리.
- **Concurrent Update Handling**: 동시에 여러 명 접속 시 데이터 충돌 방지를 위해 마지막 업데이트 시간 체크 로직 고려.
