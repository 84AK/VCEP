# PRD: Pet Shelter (디지털 펫 보호소)

## 1. 프로젝트 개요
브라우저를 닫아도 죽지 않는 디지털 펫을 키우는 앱으로, 펫의 상태(배고픔, 청결도, 행복도)를 실시간으로 구글 시트에 동기화하여 연속적인 육성 경험을 제공합니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 디지털 펫을 키우고 싶지만 브라우저를 끄면 초기화되는 것이 싫은 사용자
- **문제 정의**: 로컬 스토리지에만 저장하면 기기 이동 시 펫이 사라지거나 데이터가 손실됨. 클라우드 기반의 영구적인 펫 상태 관리가 필요함.

## 3. 핵심 기능 (Key Features)
- **상태 실시간 동기화**: 밥 주기, 씻기기 등 활동 결과가 즉시 구글 시트에 업데이트됨
- **시간 경과 반영**: 마지막 접속 시간과 현재 시간을 비교하여 부재 중 펫의 상태 변화를 계산 (GAS에서 처리)
- **성장 단계 시스템**: 누적된 활동 데이터를 바탕으로 펫이 진화하거나 새로운 스킬을 습득
- **공동 관리 (선택)**: 시트 공유를 통해 친구와 함께 한 마리의 펫을 돌보는 멀티 플레이어 요소 구현 가능

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Kawaii Aesthetics**: 고해상도 픽셀 아트와 귀여운 애니메이션 효과
- **Progressive Disclosure**: 현재 필요한 상태 정보만 상단에 배치하고 상세 스탯은 하단에 숨김 처리
- **Nature-Inspired Colors**: 편안함을 주는 초록색과 흙색 계열의 배색

## 5. 기술 스택
- **Frontend**: HTML5, CSS (Pixel Rendering), Vanilla JS
- **Backend**: Google Apps Script (GAS) - 주기적 상태 업데이트 처리
- **Database**: Google Sheets

## 6. 사용자 흐름
1. 펫 분양 받기 -> 2. 실시간 상태(Hunger 등) 확인 -> 3. 상호작용(Feed, Wash) 수행 -> 4. 상태값이 시트에 자동 저장 -> 5. 재접속 시 시트에서 마지막 상태 불러오기

## 7. 데이터 관리 전략
- **State Synchronization**: `PetStatus` 시트를 통해 `status_id`, `value`, `last_updated` 필드 관리.
- **Background Logic**: 사용자가 접속하지 않아도 시간이 지나면 배고픔 수치가 깎이는 로직을 GAS doGet 호출 시 계산하여 반영.
