# PRD: 익명 신고 앱

## 1. 프로젝트 개요
학교폭력 및 괴롭힘 발생 시 피해자나 목격자가 신원 노출의 두려움 없이 안전하게 학교나 관련 기관에 신고하고 도움을 요청할 수 있는 익명 제보 플랫폼입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 폭력 상황을 겪거나 목격했지만 보복이 두려워 말하지 못하는 중학생
- **문제 정의**: 신고 시 신원이 밝혀질 것에 대한 공포가 가장 큰 장벽이며, 이로 인해 폭력이 음성화되고 피해가 누적됨.

## 3. 핵심 기능 (Key Features)
- **완전 익명 제보**: 보낸 이의 정보를 식별할 수 없는 보안 기술 적용 메시지 발송
- **증거 자료 첨부**: 사진, 텍스트, 음성 등 폭력 상황의 증거를 안전하게 업로드
- **실시간 상담 연결**: 신고 접수 즉시 전문 상담 교사나 기관과 익명으로 채팅 연결
- **신고 진행 상태 조회**: 나의 제보가 어떻게 처리되고 있는지(접수, 조사 중, 완료) 익명으로 확인

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Privacy-First Design**: 앱 실행 시 즉시 기록을 지울 수 있는 '긴급 탈출' 버튼 배치
- **Soft UI (Neumorphism)**: 심리적 안정을 주는 부드럽고 차분한 인터페이스 디자인
- **Minimalist Layout**: 당황한 상황에서도 쉽고 빠르게 신고할 수 있는 최소한의 입력 단계

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Backend**: Firebase Firestore (익명 메시징) 및 Cloud Storage
- **Security**: 데이터 암호화 및 IP 추적 방지 로직 적용

## 6. 사용자 흐름
1. 익명 제보 작성창 접속 -> 2. 상황 설명 및 증거 자료 첨부 -> 3. 발송 완료 -> 4. 관리자 답변 및 처리 현황 확인

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 고보안 익명 제보 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 실행 환경을 통해 제보 시스템 동작 확인 및 배포
- **데이터 저장**: 제보 내용과 증거 파일 메타데이터를 **GAS** 및 **구글 스프레드시트**를 통해 안전하게 클라우드 DB에 기록
- **보안 및 권한**: 익명성 유지를 위해 클라이언트 IP나 브라우저 정보 수집을 배제하고, GAS 연동 시 CORS 정책을 강화하여 허가된 도메인에서만 접근 가능하도록 설계
