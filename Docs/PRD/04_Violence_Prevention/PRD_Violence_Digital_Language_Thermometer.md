# PRD: 디지털 언어 체온계

## 1. 프로젝트 개요
메신저나 SNS에 게시물을 올리기 전, 내가 작성한 텍스트의 공격성이나 부정적인 감정을 AI가 실시간으로 분석하여 '온도'로 시각화해주고, 배려 있는 언어 사용을 유도하는 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 디지털 공간에서 무심코 거친 표현을 사용하는 중학생
- **문제 정의**: 텍스트 소통은 감정이 잘 전달되지 않아 오해가 생기기 쉽고, 비속어나 공격적인 표현이 사이버 불링의 시작이 됨.

## 3. 핵심 기능 (Key Features)
- **실시간 언어 분석**: 사용자가 텍스트를 입력하면 AI가 공격성, 비하, 욕설 등을 즉시 분석
- **언어 온도계**: 분석 결과에 따라 파란색(친절)에서 빨간색(공격적)까지 온도로 시각화
- **순화 표현 제안**: 거친 표현 대신 사용할 수 있는 부드럽고 명확한 공감 표현 추천
- **나의 언어 습관 통계**: 기간별 나의 평균 '언어 온도' 추이 제공

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Dynamic Color Themes**: 온도가 올라감에 따라 배경색과 UI 요소가 실시간으로 변화
- **Glassmorphism 2.0**: 온도계 위젯과 추천 문구 카드를 투명한 유리 레이어로 설계
- **Micro-interactions**: 텍스트를 고칠 때마다 온도계 바가 움직이는 역동적인 효과

## 5. 기술 스택 제안
- **Frontend**: Vanilla JS (또는 React), Tailwind CSS V4
- **AI Integration**: Gemini API를 활용한 텍스트 감정 및 공격성 분석
- **Storage**: Browser LocalStorage (통계 데이터)

## 6. 사용자 흐름
1. 메시지/게시물 텍스트 입력 -> 2. 실시간 언어 온도 확인 -> 3. 온도가 높을 경우 순화 제안 검토 -> 4. 수정 후 안전한 온도로 발송

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 고기능 AI 웹앱 개발
- **실행 및 공유**: **Google AI Studio**에서 Gemini API를 실시간 호출하여 텍스트 감정 분석 기능 확인 및 배포
- **데이터 저장**: 별도의 사용자 정보 저장이 없는 '프라이버시 중심' 설계로, 통계가 필요한 경우에만 **LocalStorage** 활용
- **보안 및 권한**: Gemini API 호출 시 CORS 에러를 방지하기 위해 정형화된 요청 구조를 사용하고, 샌드박스 보안 정책을 준수하는 비동기 처리 로직 탑재
