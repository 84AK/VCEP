# PRD: 도움 요청 가이드 앱

## 1. 프로젝트 개요
학교폭력 상황이 발생했을 때 당황하지 않고 적절하게 대처할 수 있도록 상황별 대처 매뉴얼과 긴급 연락처, 법적/행정적 도움을 받을 수 있는 절차를 안내하는 가이드 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 갑작스러운 폭력 상황에 직면하여 혼란을 겪는 중학생
- **문제 정의**: 폭력 발생 시 공포와 당혹감으로 인해 무엇을 먼저 해야 할지(신고, 증거 확보, 부모님께 알리기 등) 판단하기 어려움.

## 3. 핵심 기능 (Key Features)
- **상황별 맞춤 가이드**: 신체 폭력, 언어 폭력, 사이버 불링 등 유형별 즉각 대응 수칙 제공
- **긴급 연락처 디렉토리**: 117 학교폭력 신고센터, 청소년 모바일 상담 등 즉시 연결 버튼
- **증거 확보 체크리스트**: 캡처본 저장, 목격자 확보 등 나중에 도움이 될 증거 수집 방법 안내
- **마음 진정 모드**: 심호흡 가이드나 진정 메시지를 통해 패닉 상태를 완화하는 기능

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Large Action Icons**: 시인성이 높은 큰 아이콘과 버튼으로 긴급 상황에서의 조작 편의성 극대화
- **Bento Grid**: 긴급 연락처, 대응 수칙, 체크리스트를 직관적인 그리드로 배치
- **Step-by-step UI**: 복잡한 절차를 하나씩 따라 할 수 있는 단계별 인터페이스

## 5. 기술 스택 제안
- **Frontend**: Vanilla JS, Tailwind CSS V4
- **Storage**: Browser LocalStorage (개인 기록 저장)
- **Library**: Framer Motion (단계 전환 애니메이션)

## 6. 사용자 흐름
1. 폭력 유형 선택 -> 2. 즉각 대응 수칙 확인 -> 3. 증거 확보 체크리스트 수행 -> 4. 필요 시 긴급 전화 연결

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Gemini Canvas**를 활용한 가이드형 단일 HTML 앱 개발
- **실행 및 공유**: **Gemini Canvas** 또는 **Code Canvas**에서 즉시 실행 및 매뉴얼 확인
- **데이터 저장**: 고정된 가이드 콘텐츠 위주로 구성하며, 개인적인 체크리스트 진행 상황은 **LocalStorage**에 저장 (서버리스 방식)
- **보안 및 권한**: 긴급 연락처 연결(Tel API) 등 브라우저 보안 권한이 필요한 경우, 샌드박스 환경 내에서 정상 작동하도록 명시적 사용자 인터랙션 유도 로직 포함
