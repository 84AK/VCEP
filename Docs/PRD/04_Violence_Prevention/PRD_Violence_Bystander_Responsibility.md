# PRD: 방관자 책임 학습 앱

## 1. 프로젝트 개요
학교폭력 방관이 단순히 지켜보는 것이 아니라 법적/도덕적 책임이 따를 수 있음을 실제 사례와 판례를 통해 학습하고, 공동체 의식을 함양하도록 돕는 교육용 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 방관의 심각성을 인지하고 정의로운 행동의 가치를 배우고 싶은 고등학생
- **문제 정의**: "나는 때리지 않았으니 상관없다"는 인식이 팽배하며, 방관이 폭력을 정당화하고 강화하는 심리적 기제임을 깨닫게 할 필요가 있음.

## 3. 핵심 기능 (Key Features)
- **사례 중심 학습**: 방관이 문제가 되었던 실제 판례 및 도덕적 딜레마 상황 분석
- **전문가 인터뷰/칼럼**: 변호사, 심리학자 등이 설명하는 방관의 책임과 영향력 콘텐츠
- **공동체 의식 퀴즈**: 학습 내용을 바탕으로 한 퀴즈와 나의 도덕적 판단 기준 점검
- **인증서 발급**: 교육 과정을 이수한 학생에게 '학교 문화 수호자' 디지털 배지/인증서 수여

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Modern Typography**: 전문적인 지식을 전달하기에 적합한 깔끔하고 신뢰감 있는 서체
- **Bento Grid**: 학습 모듈, 퀴즈 현황, 획득한 배지를 직관적으로 배치
- **Interactive Timeline**: 역사적 사례나 사건의 전개 과정을 스크롤 타임라인으로 시각화

## 5. 기술 스택 제안
- **Frontend**: HTML5, Vanilla JS, Tailwind CSS V4
- **Storage**: Browser IndexedDB (학습 진행률 저장)
- **Library**: Canvas-confetti (퀴즈 성공 시 효과)

## 6. 사용자 흐름
1. 학습 모듈 선택 -> 2. 사례 분석 및 전문가 칼럼 열람 -> 3. 확인 퀴즈 풀기 -> 4. 이수 완료 및 배지 획득

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Gemini 채팅**을 통한 교육용 단일 HTML 앱 구현
- **실행 및 공유**: **Code Canvas** 에디터의 미리보기 환경에서 학습 및 퀴즈 기능 확인
- **데이터 저장**: 학습 진행률과 배지 획득 정보는 **LocalStorage**에 저장하여 브라우저 독립적으로 관리
- **보안 및 권한**: 외부 리소스 로딩 최소화를 통해 CORS 이슈를 방지하고, 샌드박스 환경 내에서 애니메이션 효과가 부드럽게 작동하도록 CSS 기반 최적화 진행
