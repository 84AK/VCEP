# PRD: 방관자 행동 시나리오 앱

## 1. 프로젝트 개요
학교폭력 현장을 목격한 방관자들이 피해자를 돕거나 폭력을 중단시키기 위해 할 수 있는 행동들을 가상 시나리오를 통해 연습해보고, 방관이 아닌 '조력자'로 거듭나도록 돕는 시뮬레이션 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 폭력을 목격했을 때 도와주고 싶지만 방법을 모르거나 두려움을 느끼는 중학생
- **문제 정의**: 다수의 방관자가 존재할 때 폭력이 지속되기 쉬우며, 방관자 한 명의 용기 있는 행동이 상황을 바꿀 수 있음을 체감하게 함.

## 3. 핵심 기능 (Key Features)
- **인터랙티브 시나리오**: 교실, 급식실, 단톡방 등에서 발생하는 폭력 상황 시뮬레이션
- **행동 선택지 제공**: '도움 요청하기', '말리기', '피해자 챙기기' 등 다양한 선택지와 그에 따른 결과 확인
- **안전한 도움 방법 안내**: 자신도 위험에 빠지지 않으면서 상황을 지혜롭게 해결하는 팁 제공
- **방관자 지수 테스트**: 평소 나의 태도를 점검하고 조력자로 변화하기 위한 맞춤형 조언 제공

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Immersive Storytelling**: 애니메이션과 일러스트를 활용한 몰입감 있는 시나리오 전개
- **Glassmorphism 2.0**: 선택지 버튼과 결과 창에 세련된 반투명 효과 적용
- **Scroll-driven Animations**: 이야기의 흐름에 따라 배경이 변화하는 효과

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Animations**: Framer Motion (캐릭터 및 상황 전환)
- **Logic**: 상태 기반 시나리오 분기 엔진 구축

## 6. 사용자 흐름
1. 연습 시나리오 선택 -> 2. 상황 전개 시청 및 행동 선택 -> 3. 행동에 따른 결과 및 피드백 확인 -> 4. 올바른 조력자 행동 지침 학습

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 시나리오 분기형 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 또는 **Gemini Canvas**에서 인터랙티브 시나리오 실행 및 공유
- **데이터 저장**: 시나리오 데이터는 JSON으로 내장하고, 사용자의 선택 통계 등은 **LocalStorage** 또는 필요 시 **GAS**를 통해 익명으로 수집
- **보안 및 권한**: 샌드박스 환경 내에서 복잡한 JS 로직이 실행될 때 보안 차단이 발생하지 않도록 모듈화된 클린 코드 구조 유지
