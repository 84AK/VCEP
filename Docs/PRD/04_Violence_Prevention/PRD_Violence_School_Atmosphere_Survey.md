# PRD: 학교 분위기 익명 설문 앱

## 1. 프로젝트 개요
학생들이 느끼는 우리 학교의 안전도, 친구 관계의 질, 선생님과의 소통 만족도 등을 익명으로 정기 설문하여, 학교의 건강 상태를 수치로 진단하는 학교 문화 진단 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 학교 문화를 스스로 개선하고 싶은 고등학생
- **문제 정의**: 겉으로 드러나지 않는 학교폭력의 징후나 학생들의 심리적 불안을 데이터로 파악하지 못하면 선제적인 예방이 어려움.

## 3. 핵심 기능 (Key Features)
- **정기 안전 설문**: 매주/매달 학교 생활의 안전함에 대한 익명 투표 및 설문
- **우리 학교 안전 지수**: 설문 결과를 바탕으로 산출된 실시간 안전도 점수 표시
- **익명 건의함**: 학교 분위기 개선을 위해 학생회나 선생님께 전달하고 싶은 익명 의견 제안
- **데이터 대시보드**: 학년별, 기간별 분위기 변화 추이를 그래프로 시각화

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Bento Grid**: 설문 참여, 현재 지수, 공지사항을 직관적인 그리드로 배치
- **Interactive Graphs**: 설문 결과를 실시간으로 반영하여 변하는 역동적인 차트
- **Glassmorphism 2.0**: 설문 문항 카드에 세련된 반투명 효과 적용

## 5. 기술 스택 제안
- **Frontend**: HTML5, Vanilla JS, Tailwind CSS V4
- **Backend**: Google Sheets API (GAS) - 설문 데이터 수집 및 분석
- **Charts**: Chart.js (안전 지수 추이 그래프)

## 6. 사용자 흐름
1. 정기 설문 알림 확인 -> 2. 익명 설문 응답(매우 안전~매우 불안 등) -> 3. 전체 학생들의 응답 통계 확인 -> 4. 건의 사항 제출

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 데이터 수집형 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 실행 환경을 통해 실시간 설문 참여 및 결과 대시보드 동작 확인
- **데이터 저장**: 설문 응답 데이터를 **GAS**를 활용하여 **구글 스프레드시트**에 익명 상태로 안전하게 수집 및 누적
- **보안 및 권한**: 익명성 보장을 위해 중복 응답 방지 로직을 브라우저 핑거프린팅 대신 **LocalStorage** 기반으로 설계하고, GAS 통신 시 발생할 수 있는 CORS 이슈를 리다이렉션 최적화로 해결
