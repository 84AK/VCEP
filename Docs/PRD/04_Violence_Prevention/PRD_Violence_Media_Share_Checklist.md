# PRD: 사진·영상 공유 전 체크리스트

## 1. 프로젝트 개요
사진이나 동영상을 SNS에 공유하기 전, 타인의 초상권, 저작권, 그리고 해당 미디어가 누군가에게 상처가 되지는 않을지 스스로 점검하게 하는 디지털 에티켓 체크리스트 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 디지털 미디어 공유가 빈번한 중학생
- **문제 정의**: 재미를 위해 올린 친구의 굴욕 사진이나 영상이 당사자에게는 씻을 수 없는 상처가 되고 사이버 폭력으로 번지는 사례가 많음.

## 3. 핵심 기능 (Key Features)
- **미디어 업로드 점검**: 공유할 사진/영상을 불러오면 체크리스트 시작
- **5대 필수 체크항목**: '당사자의 동의를 얻었는가?', '배경에 타인의 얼굴이 찍혔는가?', '비하하는 내용이 포함되었는가?' 등
- **개인정보 보호 가이드**: 사진 속 위치 정보(EXIF) 삭제나 타인 얼굴 가리기 기능 안내
- **안전 공유 승인**: 모든 체크리스트를 통과해야만 '안전한 미디어' 승인 배지 부여

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Step-by-step UI**: 한 화면에 하나의 질문만 배치하여 집중도 향상
- **Bento Grid**: 완료된 체크리스트 기록과 개인정보 보호 팁을 박스 형태로 배치
- **Vibrant & Warning Colors**: 주의가 필요한 항목에는 시인성 높은 색상 사용

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Image Processing**: Canvas API (간단한 모자이크나 텍스트 가리기 기능)
- **Storage**: Browser IndexedDB

## 6. 사용자 흐름
1. 공유할 사진 선택 -> 2. 단계별 체크리스트 응답 -> 3. 미흡한 부분(초상권 등) 수정 -> 4. 최종 안전 확인 및 SNS 공유

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Gemini Canvas**를 활용한 미디어 처리형 단일 HTML 앱 개발
- **실행 및 공유**: **Gemini Canvas** 또는 **Code Canvas**에서 직접 사진을 업로드하여 체크리스트 동작 테스트
- **데이터 저장**: 업로드된 사진은 서버에 저장되지 않는 'Client-side Only' 방식을 채택하고, 체크리스트 로그는 **LocalStorage**에 저장
- **보안 및 권한**: 샌드박스 환경 내에서 파일 접근 권한(`input type="file"`)이 원활하게 작동하도록 표준 API를 사용하고, 외부 스크립트 의존도를 최소화하여 보안 충돌 방지
