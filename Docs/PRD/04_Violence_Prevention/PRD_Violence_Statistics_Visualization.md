# PRD: 학교폭력 통계 시각화

## 1. 프로젝트 개요
전국 및 지역별 학교폭력 실태 조사 데이터를 기반으로, 폭력의 유형, 발생 장소, 신고율 등의 변화를 인터랙티브한 대시보드로 시뮬레이션하여 폭력 예방의 중요성을 강조하는 데이터 웹입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 데이터 분석을 통해 학교폭력 예방 정책에 기여하고 싶은 고등학생
- **문제 정의**: 학교폭력 통계는 복잡하고 방대하여 학생들이 그 심각성을 객관적으로 인지하기 어려우며, 데이터 기반의 예방 대책 수립이 필요함.

## 3. 핵심 기능 (Key Features)
- **전국 폭력 지도**: 전국 지도를 기반으로 지역별 학교폭력 발생 건수 및 유형 시각화
- **유형별 트렌드 분석**: 신체 폭력 vs 사이버 폭력의 연도별 변화 추이를 비교 분석
- **예방 정책 시뮬레이션**: 특정 예방 활동(예: 익명 신고제 도입) 시 예상되는 폭력 감소 효과 시뮬레이션
- **인포그래픽 리포트**: 발표나 과제에 즉시 활용 가능한 고해상도 통계 이미지 생성

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Bento Grid**: 지도, 추이 그래프, 핵심 인사이트를 그리드 레이아웃으로 배치
- **Scroll-driven Animations**: 데이터 스토리에 따라 차트가 변화하는 스크롤 효과
- **Modern Typography**: 전문적이고 신뢰감 있는 서체 사용

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Visualization**: D3.js 또는 Chart.js
- **Data Source**: 공공데이터포털(data.go.kr) 학교폭력 실태조사 데이터 활용

## 6. 사용자 흐름
1. 대시보드 메인 접속 -> 2. 분석하고 싶은 지역/연도/유형 선택 -> 3. 통계 시각화 결과 및 인사이트 확인 -> 4. 리포트 이미지 저장

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 데이터 시각화 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 환경에서 인터랙티브 차트 및 지도 데이터 동작 확인 및 배포
- **데이터 저장**: 대용량 통계 데이터를 **JSON** 파일로 최적화하여 내장하거나, 최신 데이터 업데이트를 위해 **GAS**를 통해 **구글 스프레드시트**에서 호출
- **보안 및 권한**: 시각화 라이브러리(D3.js, Chart.js 등)의 샌드박스 내 렌더링 성능 이슈를 방지하기 위해 가상 DOM 최적화 기법 적용 및 CORS 정책을 완벽히 준수하도록 설정
