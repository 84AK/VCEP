# PRD: 심해의 파동 (Bioluminescent Fluid)

## 1. 개요 (Overview)
- **앱 이름**: 심해의 파동: 감정의 소용돌이 (Bioluminescent Fluid)
- **카테고리**: 02_Mental_Health (감정 및 정신건강)
- **목적**: 복잡하게 얽힌 감정을 빛나는 유체 시뮬레이션으로 시각화하여, 마음의 혼란을 예술적으로 승화시키고 시각적 명상을 통해 평온을 되찾음.

## 2. 핵심 기능 (Key Features)
- **유체 시뮬레이션 (Fluid Dynamics)**: 마우스/터치 드래그에 반응하는 고성능 물리 엔진.
- **생물 발광 연출 (Bioluminescence)**: 어두운 심해에서 스스로 빛나는 형광빛 입자 및 트레일 효과.
- **감정 모드 인퓨전**:
  - Calm(💧), Anger(🔥), Joy(✨), Sad(🌌) 모드에 따른 유체의 점성과 색상 변화.
- **시각적 ASMR**: 유체의 흐름과 동기화된 물방울 터지는 사운드 피드백.

## 3. 기술 스택 (Tech Stack)
- **Graphics**: Canvas API (고성능 입자 시스템), WebGL (향후 확장 고려).
- **Audio**: Web Audio API (심해 앰비언트 및 반응형 SFX).
- **Layout**: CSS Glassmorphism UI Overlay.

## 4. 디자인 원칙
- **추상적 수용 (Abstract Acceptance)**: 감정을 형태가 없는 유체로 표현하여 판단 없이 흐르게 함.
- **압도적 비주얼**: 2026년형 프리미엄 다크 모드 및 발광 효과 적용.
