# PRD: 다정한 마음 배달부 (The Empathy Postman)

## 1. 개요 (Overview)
- **앱 이름**: 다정한 마음 배달부 (The Empathy Postman)
- **카테고리**: 02_Mental_Health (감정 및 정신건강)
- **목적**: 타인의 고민에 대해 올바르게 공감하는 방법을 시뮬레이션을 통해 익히고, 다정한 언어의 힘을 체험함.

## 2. 핵심 기능 (Key Features)
- **마음 우체국 시뮬레이션**: 사용자가 우체부/우체국장이 되어 익명의 고민 편지를 수신.
- **공감 선택지 시스템**: 3가지 답변(충고 위주, 방관형, 깊은 공감형) 중 하나를 선택하는 인터랙티브 퀴즈 형식.
- **감성적 피드백**: 올바른 공감을 선택할 때마다 화면의 '행복 게이지'가 차오르며 우체국이 꽃과 빛으로 장식되는 시각적 보상.
- **수집 요소**: 성공적으로 답장을 보낸 편지들은 '다정함 아카이브'에 저장되어 언제든 다시 읽을 수 있음.

## 3. 기술 스택 (Tech Stack)
- **Frontend**: HTML5, Vanilla CSS (Transition & Animation), JavaScript (State Management).
- **Design**: Cozy & Warm aesthetic, Hand-drawn illustrations.
- **Audio**: Web Audio API (편지 여는 소리, 종소리, 따뜻한 BGM).

## 4. 디자인 원칙
- **비심판적 환경**: 틀린 답변을 골라도 꾸짖기보다는 "상대방은 조금 서운해할지도 몰라요"와 같은 부드러운 가이드를 제공.
- **따뜻한 색조**: 우드 톤, 베이지, 코랄 핑크 등 온기가 느껴지는 색상 팔레트.
- **Bento Grid Layout**: 우체국의 여러 도구들(도장, 편지함, 배지)을 벤토 그리드 스타일로 배치.
