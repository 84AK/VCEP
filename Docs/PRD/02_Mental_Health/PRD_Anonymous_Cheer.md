# PRD: 응원의 종이비행기 (Paper Planes of Cheer)

## 1. 개요 (Overview)
- **앱 이름**: 응원의 종이비행기: 익명 메시지 (Paper Planes of Cheer)
- **카테고리**: 02_Mental_Health (감정 및 정신건강)
- **목적**: 누군가를 향한 따뜻한 응원을 종이비행기에 실어 날려 보냄으로써, 연결감과 이타심을 고취하고 긍정적인 에너지를 순환시킴.

## 2. 핵심 기능 (Key Features)
- **비행기 작성 리추얼**: 편지지 모양의 입력창에 응원을 적고 날리기 버튼을 누르면, 종이가 비행기로 접히며 하늘로 날아가는 연출.
- **익명의 메시지 포착 (Catch a Plane)**: 화면을 가로질러 날아가는 다양한 색상의 익명 비행기들을 터치하여 펼쳐보고, 타인이 남긴 응원 메시지를 확인.
- **하늘 배경 시뮬레이션**: 시간대나 감정에 따라 변화하는 역동적인 하늘 배경(Scrolling Clouds).
- **이타적 피드백**: 비행기를 날릴 때 퍼지는 은은한 빛의 파티클과 경쾌한 바람 소리.

## 3. 기술 스택 (Tech Stack)
- **Frontend**: HTML5, Vanilla CSS (Keyframe Animations), JavaScript (Physics-lite movement).
- **Backend**: 향후 GAS 연동을 통한 글로벌 메시지 공유 (현재는 시뮬레이션 데이터 사용).
- **Audio**: Web Audio API (바람 소리, 종이 사각거리는 소리).

## 4. 디자인 원칙
- **개방감 (Openness)**: 답답한 마음을 해소해 줄 수 있는 광활하고 맑은 하늘 이미지.
- **희망적 색채**: 파스텔 블루, 화이트, 그리고 포인트가 되는 따뜻한 옐로우/오렌지 색상.
- **동적 경험**: 끊임없이 움직이는 비행기와 구름을 통해 생동감 부여.
