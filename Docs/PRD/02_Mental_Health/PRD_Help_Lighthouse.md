# PRD: 마음의 등대 (The Lighthouse: Help Guide)

## 1. 개요 (Overview)
- **앱 이름**: 마음의 등대: 도움 요청 가이드 (The Lighthouse)
- **카테고리**: 02_Mental_Health (감정 및 정신건강)
- **목적**: 전문 기관(병원, 상담소) 방문에 대한 심리적 장벽을 낮추고, 구체적인 행동 지침(스크립트, 위치 정보)을 제공하여 용기 있는 첫걸음을 돕는 가이드 앱.

## 2. 핵심 기능 (Key Features)
- **안개 걷기(Fog Clearing) 인터렉션**: 5단계 가이드를 읽을 때마다 화면의 안개가 걷히며 등대가 선명해지는 스토리텔링형 UI.
- **자가 진단 & 수용 (Acceptance)**: 현재 상태를 체크하고 "도움을 받는 것은 당연한 권리"임을 인지시켜주는 긍정 확언 섹션.
- **실전 상황별 스크립트 (Call Scripts)**:
  - 상담 예약 전화 템플릿
  - 처음 상담실에 들어갔을 때 첫 마디 가이드
- **안전한 피난처 지도 (Safe Haven Map)**: 공신력 있는 기관(정신건강복지센터 등) 정보 제공.
- **용기 배지 (Courage Badge)**: 가이드를 완독한 사용자에게 부여하는 리워드.

## 3. 기술 스택 (Tech Stack)
- **Frontend**: HTML5, Vanilla CSS (Fog Filter Effects), JavaScript (Step Logic).
- **Audio**: Web Audio API (파도 소리와 등대 종소리의 평온한 앰비언스).
- **Design**: Peachy & Soft Yellow Gradient (따뜻하고 안전한 느낌).

## 4. 디자인 원칙
- **동화적 수용 (Fairytale Acceptance)**: 마주하기 힘든 현실을 따뜻한 비유와 일러스트로 감싸 안아 사용자의 심리적 저항을 최소화함.
- **아날로그 감성**: 수채화풍 일러스트, 빛바랜 종이 질감, 손글씨 느낌의 폰트 적용.
- **다정한 스토리텔링**: "안개 너머 등대를 찾아서"라는 서사적 구조를 가진 단계별 가이드.
