# PRD: 기억의 등불 (Message Lantern)

## 1. 개요 (Overview)
- **앱 이름**: 기억의 등불: 익명 속마음 (Message Lantern)
- **카테고리**: 02_Mental_Health (감정 및 정신건강)
- **목적**: 누구에게도 말하지 못한 진심이나 응원을 등불에 실어 밤하늘로 띄우며, 타인의 온기를 익명으로 나누어 고립감을 해소함.

## 2. 핵심 기능 (Key Features)
- **등불 작성 리추얼**: 종이 등불 텍스처 위에 직접 메시지를 적고 촛불을 켜는 상호작용.
- **하늘로 띄우기 (Floating)**: 등불이 호수 위 밤하늘로 서서히 떠오르며 작아지는 원근감 연출.
- **익명 응원의 바다**: 밤하늘을 수놓은 수많은 다른 등불들을 터치하여 타인이 남긴 응원 메시지 확인.
- **앰비언트 사운드**: 고요한 밤의 호수 소리와 은은하게 울리는 종소리 배경음.

## 3. 기술 스택 (Tech Stack)
- **Frontend**: Canvas API (등불 군집 비행 시뮬레이션), CSS 3D Transforms.
- **Backend**: Google Apps Script (GAS) 연동을 통한 익명 메시지 데이터베이스 구축.
- **Audio**: Web Audio API 기반의 공간감 있는 사운드 디자인.

## 4. 디자인 원칙
- **서정적 연대 (Lyric Solidarity)**: "나만 혼자가 아니다"라는 느낌을 주는 따뜻하고 오렌지색 중심의 광원 설계.
- **시네마틱 연출**: 등불이 띄워지는 순간의 카메라 워킹 및 포커스 효과.
