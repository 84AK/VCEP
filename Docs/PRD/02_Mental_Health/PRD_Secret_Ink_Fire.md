# PRD: 비밀 잉크와 불꽃 (Secret Ink & Fire)

## 1. 개요 (Overview)
- **앱 이름**: 비밀 잉크와 불꽃 (Secret Ink & Fire)
- **카테고리**: 02_Mental_Health (감정 및 정신건강)
- **목적**: 누구에게도 말하지 못한 속마음을 적고, 불꽃으로 확인하거나 태워버림으로써 정서적 정화(Catharsis)를 경험함.

## 2. 핵심 기능 (Key Features)
- **시네마틱 리추얼**: 투명 잉크 입력 시스템 및 고해상도 종이 소각 애니메이션.
- **사운드 엔진 (Web Audio API)**:
  - BGM: 디지털 칼림바 시퀀서를 이용한 따뜻하고 반복적인 선율.
  - SFX: 성냥 마찰음, 종이 타는 ASMR, 마법의 차임벨 소리를 코드로 직접 합성.
- **영혼의 빛 수집**: 타버린 종이가 황금빛 반딧불이로 변하여 유리병(Sacred Jar)에 수집됨.

## 3. 기술 스택 (Tech Stack)
- **Frontend**: HTML5, Vanilla CSS (Glassmorphism 2.0), Canvas API (Particle System).
- **Audio**: Web Audio API (Oscillator, Gain, BiquadFilter).
- **Storage**: LocalStorage (Soul Light 데이터 보존).

## 4. UI/UX 디자인 원칙
- **현실성 (Reality)**: 어두운 나무 질감의 테이블과 은은한 주변 광원 효과.
- **몰입감 (Immersion)**: 입력 중 텍스트 투명화 및 실시간 타격감 있는 애니메이션.
