# PRD: 감정 날씨 일기

## 1. 프로젝트 개요
오늘의 복잡한 감정을 날씨 아이콘과 텍스트로 기록하여 시각화하고, 시간에 따른 기분 변화를 추적함으로써 정서적 안정을 돕는 감정 일기 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 자신의 감정을 말로 표현하기 어려워하는 중학생
- **문제 정의**: 감정은 실체가 없어 관리하기 어렵고, 우울하거나 화난 감정이 들 때 이를 객관적으로 바라볼 도구가 필요함.

## 3. 핵심 기능 (Key Features)
- **날씨 기반 감정 선택**: 맑음(행복), 흐림(우울), 번개(분노) 등 날씨 아이콘으로 감정 선택
- **감정 일기 작성**: 해당 감정을 느낀 이유를 짧은 텍스트나 음성으로 기록
- **감정 캘린더**: 한 달간의 감정 날씨를 캘린더 형태로 시각화
- **기분 통계 리포트**: "이번 주는 '맑음'이 70%였습니다"와 같은 긍정/부정 통계 제공

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Glassmorphism 2.0**: 날씨 상태에 따라 배경 유리 효과의 색상과 질감이 실시간으로 변경
- **Micro-animations**: 아이콘 클릭 시 구름이 걷히거나 비가 내리는 등의 역동적인 효과
- **Bento Grid**: 캘린더와 통계 요약을 깔끔한 박스 레이아웃으로 배치

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Animations**: Framer Motion (날씨 전환 효과)
- **Backend**: Google Sheets API (GAS) - 일기 데이터 저장

## 6. 사용자 흐름
1. 오늘 감정 아이콘 선택 -> 2. 일기 내용 입력 -> 3. 저장 및 캘린더 확인 -> 4. 주간 감정 분석 리포트 확인
