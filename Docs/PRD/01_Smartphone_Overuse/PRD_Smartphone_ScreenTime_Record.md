# PRD: 시간 도둑 현상수배 (스마트폰 스크린타임 기록 앱)

## 1. 프로젝트 개요
사용자가 무의식적으로 소비한 스마트폰 앱과 시간을 '시간 도둑'으로 규정하고, 이를 현상수배 전단지 형식으로 시각화하여 재미있게 기록하고 반성할 수 있도록 돕는 게이미피케이션 기록 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 스마트폰 중독을 인지하고 재미있게 사용 습관을 개선하고 싶은 청소년
- **문제 정의**: 기존의 스크린타임 기록은 지루하고 데이터 중심적이라 금방 흥미를 잃음. 이를 '도둑을 잡는다'는 스토리텔링과 결합하여 지속적인 기록 동기를 부여함.

## 3. 핵심 기능 (Key Features)
- **현상수배 발령**: 앱 이름과 도둑맞은 시간(분)을 입력하면 즉시 수배 전단지(Poster) 생성
- **도둑 몬스터 생성**: 입력된 시간에 따라 랭킹(S, A, 일반)이 정해지며, 개성 있는 몬스터 이미지가 캔버스에 렌더링됨
- **도둑의 변명**: 전단지를 클릭하면 해당 앱이 시간을 훔친 이유(알고리즘 등)를 말풍선으로 표시
- **체포 미션**: '체포하기' 버튼을 누르면 간단한 행동 미션(눈 깜빡이기 등)을 수행한 후 기록을 완료함

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Chunky UI / Retro Poster**: 코르크 보드 텍스처와 투박하면서도 힙한 전단지 디자인 적용
- **Animations**: 전단지가 보드에 '쾅' 하고 박히는 Slam Down 애니메이션
- **Haptic Feedback**: 도둑을 클릭하거나 수배령을 내릴 때 진동 피드백 제공

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Custom Properties, Grid, Animations)
- **Graphic**: Canvas API를 활용한 몬스터 이미지 렌더링 및 필터링
- **Storage**: 브라우저 **localStorage**를 활용한 독립적인 데이터 저장 (Standalone)

## 6. 사용자 흐름 (User Flow)
1. 앱 접속 -> 2. 앱 이름과 시간 입력 -> 3. 수배령 발령 버튼 클릭 -> 4. 생성된 전단지 확인 -> 5. 도둑 클릭하여 변명 확인 -> 6. 체포 미션 수행 및 기록 완료

## 7. 데이터 관리 전략
- **로컬 저장소 전용**: 본 앱은 사용자의 프라이버시를 보호하고 오프라인에서도 작동하도록 **localStorage**만을 사용하며, 외부 서버(GAS 등)와의 연동 없이 단독으로 실행됨.
- **데이터 구조**: `vcep_thieves_v2` 키에 객체 배열 형태로 저장되어 앱 재접속 시에도 이전 수배 기록을 유지함.
