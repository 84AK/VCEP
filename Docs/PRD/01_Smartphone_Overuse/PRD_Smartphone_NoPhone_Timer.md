# PRD: 폰 안 보기 타이머 (No-Phone Timer)

## 1. 프로젝트 개요
공부나 작업 중 스마트폰의 유혹에서 벗어날 수 있도록 도와주는 미니멀하고 세련된 타이머 앱입니다. 직관적인 UI를 통해 집중 시간을 설정하고 성공 경험을 쌓아갈 수 있도록 돕습니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 스마트폰 알림 때문에 집중이 자주 끊기는 학생 및 직장인
- **문제 정의**: 습관적으로 스마트폰을 확인하는 행동을 방지하기 위해, 시각적으로 명확한 '금지 시간'을 설정하고 이를 달성하는 성취감을 제공하고자 함.

## 3. 핵심 기능 (Key Features)
- **미니멀 타이머**: 5분 단위로 빠르게 시간을 설정할 수 있는 퀵 버튼 및 수동 설정 기능
- **시각적 카운트다운**: 원형 프로그레스 바와 함께 남은 시간을 Outfit 폰트의 볼드한 숫자로 표시
- **집중 성공 기록**: 타이머 완료 시 '성공'으로 간주하고 해당 세션의 데이터를 로컬에 저장
- **최근 기록 확인**: 하단 리스트를 통해 오늘 얼마나 집중했는지 직전 기록들을 확인

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Glassmorphism 2.0**: 블러 효과와 세련된 그라데이션이 적용된 프로스트 글래스 효과
- **Premium Typography**: Outfit 및 Inter 폰트를 사용하여 모던하고 깔끔한 분위기 조성
- **Smooth Interaction**: 버튼 클릭 시 부드러운 스케일 애니메이션과 전환 효과 적용

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Custom Properties, Flexbox)
- **Animations**: CSS Transition 및 SVG Path 애니메이션 (Circular Progress)
- **Storage**: 브라우저 **localStorage**를 활용한 데이터 저장 (Standalone)

## 6. 사용자 흐름
1. 앱 접속 -> 2. 집중 시간 선택 (5분, 10분, 30분 등) -> 3. 시작 버튼 클릭 -> 4. 집중 수행 (카운트다운 진행) -> 5. 완료 알림 및 기록 자동 저장

## 7. 데이터 관리 전략
- **Local Persistence**: 타이머 완료 시 `vcep_nophone_timer` 키를 통해 로컬 스토리지에 세션 데이터(날짜, 시간, 상태)를 저장함.
- **Standalone Focus**: 외부 서버(GAS 등) 연동 없이 모든 타이밍 로직과 데이터 처리가 브라우저 내에서 완벽하게 수행되어 보안성과 속도를 극대화함.
