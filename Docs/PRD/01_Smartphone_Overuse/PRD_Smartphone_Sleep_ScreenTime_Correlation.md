# PRD: 오늘의 시간 일기 (수면 질 + 스크린타임 상관관계 분석)

## 1. 프로젝트 개요
나의 수면 데이터와 스마트폰 사용 데이터를 기록하고, 둘 사이의 밀접한 관계를 캐릭터와 차트를 통해 직관적으로 분석해주는 시간 기록 일기 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 스마트폰 사용이 수면에 미치는 영향을 직접 눈으로 확인하고 싶은 학생
- **문제 정의**: 늦은 시간까지의 스마트폰 사용이 다음 날의 컨디션(수면 질)을 어떻게 망치는지 구체적인 인과관계를 파악하기 어려움.

## 3. 핵심 기능 (Key Features)
- **시간 일기 작성**: 어젯밤 수면 시간, 수면 만족도(점수), 그리고 어제 총 스마트폰 사용 시간을 간편하게 입력
- **도둑 캐릭터 피드백**: '시간 도둑' 캐릭터 이미지를 통해 입력 데이터에 따른 시각적 상태 변화(활기참, 피곤함 등) 확인
- **상관관계 분석 보드**: 입력된 데이터를 바탕으로 수면 질과 스마트폰 사용량의 상관관계를 차트로 분석
- **히스토리 관리**: 과거의 기록들을 리스트로 확인하고 생활 습관의 변화를 추적

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Glassmorphism 2.0**: 입력 필드와 결과 카드에 깊이감 있는 유리 효과와 부드러운 그림자 적용
- **Chunky UI**: 큼직하고 명확한 입력 버튼과 상태 배지(Badge) 디자인
- **Visual Storytelling**: '시간 도둑' 캐릭터를 활용하여 딱딱한 데이터 분석을 친근하게 전달

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Flexbox, Grid, Transitions)
- **Graphic**: 외부 이미지 리소스 및 Canvas를 활용한 캐릭터 렌더링
- **Storage**: 브라우저 **localStorage**를 활용한 데이터 저장 (Standalone)

## 6. 사용자 흐름
1. 앱 접속 -> 2. 수면 시간, 수면 점수, 스마트폰 사용 시간 입력 -> 3. 기록 저장 버튼 클릭 -> 4. 캐릭터 피드백 및 상관관계 분석 결과 확인 -> 5. 하단 히스토리 리스트를 통해 누적 데이터 열람

## 7. 데이터 관리 전략
- **Local Database**: `vcep_time_diary` 키를 사용하여 사용자의 모든 일기 기록을 로컬 스토리지에 배열 형태로 안전하게 저장함.
- **Standalone Privacy**: 클라우드 연동 없이 로컬 기기 내에서만 데이터를 처리하여 사용자의 민감한 수면 및 건강 정보를 안전하게 보호함.
