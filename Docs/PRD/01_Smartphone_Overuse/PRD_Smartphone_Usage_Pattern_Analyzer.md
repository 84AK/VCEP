# PRD: 도파민 수사대 (앱별 사용 패턴 분석기)

## 1. 프로젝트 개요
사용자의 스마트폰 사용 데이터를 기반으로 '도파민 중독 지수'를 분석하고, 어떤 카테고리에 뇌가 자극받고 있는지 수사관의 관점에서 시각화해주는 정밀 분석 도구입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 자신의 스마트폰 사용 패턴을 정밀하게 알고 싶은 청소년 및 성인
- **문제 정의**: 단순히 사용 시간을 아는 것을 넘어, 본인이 '도파민 추구형'인지 '생산성 추구형'인지 구체적인 성향 파악이 필요함.

## 3. 핵심 기능 (Key Features)
- **도파민 레이더 차트**: SNS, 게임, 영상, 도구, 학습 등 카테고리별 비중을 5각형 레이더 차트로 시각화
- **중독 유형 판독**: 분석 결과에 따라 '도파민 중독 수사 대상', '건전한 시민', '디지털 명상가' 등의 유형 판독 결과 제공
- **데이터 요약 카드**: 가장 많이 사용한 앱, 생산성 앱 비율, 주간 변화 추이를 Bento Grid 형태의 카드로 요약
- **수사관의 조언**: 분석된 패턴을 바탕으로 도파민을 낮추기 위한 맞춤형 피드백 제공

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Investigation Mood**: 수사 기관의 브리핑 보드 같은 느낌의 다크하고 전문적인 디자인 (Detective Theme)
- **Bento Grid Layout**: 핵심 분석 지표를 직관적인 박스 형태로 배치
- **Interactive Charts**: Chart.js를 활용하여 마우스 호버 시 상세 데이터를 보여주는 반응형 그래프

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Glassmorphism 2.0, Flexbox/Grid)
- **Library**: Chart.js (Radar Chart, Bar Chart 활용)
- **Storage**: 브라우저 **localStorage**를 활용한 독립적인 데이터 저장 (Standalone)

## 6. 사용자 흐름
1. 앱 접속 -> 2. `screen_record`를 통해 저장된 데이터 로드 -> 3. 수사 시작 버튼 클릭 -> 4. 도파민 레이더 차트 및 유형 판독 확인 -> 5. 요약 카드별 상세 분석 결과 열람

## 7. 데이터 관리 전략
- **로컬 데이터 분석**: 본 앱은 `localStorage`에 저장된 `vcep_master_data`의 `screen_record` 카테고리를 분석하여 동작함.
- **Standalone 아키텍처**: 외부 서버(GAS 등)와의 실시간 통신 없이 기기 내부의 데이터를 즉석에서 가공하여 개인정보 유출 걱정 없이 안전하게 분석을 수행함.
