# PRD: 수면 유도 양 떼 목장 (수면 전 루틴 체크 앱)

## 1. 프로젝트 개요
취침 전 스마트폰 사용을 멈추고 숙면에 들 수 있도록 돕는 명상 및 양 세기 게이미피케이션 앱입니다. 과학적인 호흡법과 시각적인 양 세기 연출을 통해 사용자의 뇌를 휴식 상태로 유도합니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 잠들기 직전까지 폰을 보느라 수면 시간이 부족한 청소년 및 성인
- **문제 정의**: 블루라이트 노출과 끊임없는 자극(Shorts 등)으로 인해 뇌가 각성 상태로 유지되어 잠들기 어려움.

## 3. 핵심 기능 (Key Features)
- **달의 호흡 가이드**: 4-7-8 호흡법(4초 흡입, 7초 멈춤, 8초 배출)에 맞춰 달이 커지고 작아지는 시각적 가이드 제공
- **양 세기 애니메이션**: 울타리를 넘는 양들을 눈으로 쫓으며 자연스럽게 수면 모드에 진입하도록 유도
- **화면 디밍(Dimming)**: 수면 모드가 지속될수록 화면이 점진적으로 어두워지며 블루라이트 차단 효과 제공
- **터치 페널티**: 수면 모드 중 화면을 터치하거나 조작하면 양들이 놀라 달아나며 수면 흐름이 깨졌음을 경고함
- **백색 소음(Pink Noise)**: 브라우저 Audio API를 활용한 부드러운 바람 소리/파도 소리 자동 재생

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Deep Night Theme**: 눈의 피로를 최소화하는 다크 네이비 배경과 은은한 별빛 연출
- **Organic Motion**: 달의 팽창과 수축, 양의 보행 스프라이트 애니메이션 등 부드러운 유기적 움직임 적용
- **Glassmorphism 2.0**: 경고창 및 인트로 모달에 세련된 반투명 블러 효과 적용

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Animation, Variables, Filter)
- **Audio**: Web Audio API를 활용한 실시간 노이즈 생성 및 필터링
- **Graphic**: Canvas API를 활용한 스프라이트 이미지의 실시간 배경 투명화 처리
- **Storage**: 브라우저 **localStorage**를 활용한 데이터 저장 (Standalone)

## 6. 사용자 흐름
1. 앱 접속 -> 2. 수면 모드 시작하기 클릭 -> 3. 달의 호흡 가이드에 맞춰 호흡 -> 4. 울타리를 넘는 양들을 세며 수면 유도 -> 5. 폰을 조작할 경우 경고 발생 -> 6. 일정 수 이상의 양을 세면 수면 기록 저장

## 7. 데이터 관리 전략
- **Local Persistence**: `vcep_sleep_routine` 키를 사용하여 성공적으로 센 양의 마릿수 기록을 로컬에 저장함.
- **Standalone Privacy**: 외부 서버 통신 없이 기기 내부에서 모든 오디오와 시각 효과가 생성되므로 데이터 유출 위험이 없으며 오프라인에서 완벽히 작동함.
