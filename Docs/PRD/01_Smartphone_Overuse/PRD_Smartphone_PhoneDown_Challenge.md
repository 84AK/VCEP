# PRD: 심심함 자판기 (폰 내려놓기 챌린지)

## 1. 프로젝트 개요
스마트폰 없이 보내는 시간을 '심심함'이 아닌 '새로운 시도'의 기회로 바꾸어주는 오프라인 활동 추천 자판기 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 폰을 안 볼 때 무엇을 해야 할지 몰라 다시 폰을 잡게 되는 '디지털 금단현상'을 겪는 청소년
- **문제 정의**: 폰을 내려놓았을 때 찾아오는 무료함을 해결할 구체적인 활동 대안이 부족함.

## 3. 핵심 기능 (Key Features)
- **미션 뽑기 레버**: 레버 버튼을 누르면 자판기가 작동하는 듯한 애니메이션과 함께 오프라인 미션이 무작위로 추첨됨
- **영수증 미션 출력**: 추첨된 미션을 실제 영수증 조각처럼 시각화하여 화면에 출력 (가독성 높은 텍스트)
- **오프라인 활동 추천**: '눈 감고 좋아하는 노래 한 곡 듣기', '창밖 먼 곳 바라보기' 등 폰 없이 할 수 있는 20여 가지 미션 제공
- **미션 완료 시스템**: 제시된 미션을 실제로 수행한 후 '완료' 버튼을 눌러 기록함

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Arcade/Vending Machine Aesthetic**: 오락실 자판기 느낌의 레트로한 디자인과 비비드한 컬러 사용
- **Micro-interactions**: 버튼 클릭 시의 기계적인 움직임, 영수증이 지이잉 올라오는 슬라이드 애니메이션
- **Sound/Vibration Visuals**: 화면 진동 효과와 시각적 노이즈를 활용한 실감 나는 연출

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Animation, Keyframes, Flex/Grid)
- **Interactions**: CSS Transform 및 Transition을 활용한 물리적인 버튼 효과
- **Storage**: 브라우저 **localStorage**를 활용한 데이터 저장 (Standalone)

## 6. 사용자 흐름
1. 앱 접속 -> 2. 자판기 레버(버튼) 클릭 -> 3. 미션 추첨 애니메이션 대기 -> 4. 출력된 영수증 미션 확인 -> 5. 실제 오프라인 활동 수행 -> 6. 미션 완료 버튼 클릭 및 기록 저장

## 7. 데이터 관리 전략
- **Local Persistence**: `vcep_phonedown_challenge` 키를 사용하여 사용자가 완료한 미션의 기록을 로컬에 저장함.
- **Standalone Focus**: 복잡한 네트워크 통신 없이 브라우저 내에서 즉각적으로 미션을 생성하고 처리하여 사용자의 몰입을 방해하지 않음.
