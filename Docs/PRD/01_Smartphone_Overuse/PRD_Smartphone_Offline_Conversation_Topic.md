# PRD: 시한폭탄 토크 (오프라인 대화 주제 생성기)

## 1. 프로젝트 개요
친구들과 모였을 때 스마트폰 없이 대화에 몰입할 수 있도록 돕는 게임형 대화 추천 앱입니다. '폭탄이 터지기 전까지 대화를 이어가야 한다'는 긴박한 설정을 통해 대화의 재미를 극대화합니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 오프라인 만남에서 대화 주제가 고갈되어 어색함을 느끼는 청소년 및 성인
- **문제 정의**: 침묵을 견디지 못해 다시 폰을 꺼내게 되는 상황을 방지하고, 게임 형식을 통해 자연스럽게 깊은 대화를 유도하고자 함.

## 3. 핵심 기능 (Key Features)
- **시한폭탄 타이머**: 대화가 시작되면 폭탄이 째깍거리며 줄어드는 애니메이션이 실행됨 (60초 내외)
- **무작위 대화 주제**: '민트초코 호불호'부터 '가장 기억에 남는 여행지'까지 30여 가지 이상의 다양한 질문 제공
- **긴장감 넘치는 연출**: 폭탄의 불꽃 애니메이션, 남은 시간에 따른 깜빡임 가속화
- **폭발 및 성공 판정**: 시간 내에 충분히 대화하고 '폭탄 해체(성공)'하거나, 대화가 끊겨 '폭발(실패)'하는 결과 시각화

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **High Tension Design**: 검은색 배경에 대비되는 강렬한 오렌지/레드 계열의 컬러 포인트 사용
- **Dynamic Visuals**: CSS Animation으로 구현된 생동감 넘치는 폭탄 불꽃과 흔들림 효과
- **Glassmorphism 2.0**: 대화 주제 카드를 세련된 반투명 디자인으로 처리

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Custom Properties, Keyframe Animations)
- **Logic**: 무작위 배열 셔플링을 통한 주제 중복 방지 로직
- **Storage**: 브라우저 **localStorage**를 활용한 데이터 저장 (Standalone)

## 6. 사용자 흐름
1. 앱 접속 -> 2. '대화 시작' 클릭 -> 3. 랜덤 대화 주제 확인 -> 4. 폭탄이 터지기 전까지 친구들과 대화 수행 -> 5. 대화 완료 후 '미션 성공' 버튼 클릭 혹은 타임오버로 인한 폭발 확인

## 7. 데이터 관리 전략
- **Local Persistence**: `vcep_offline_topic` 키를 사용하여 대화의 성공/실패 여부와 주제 기록을 로컬에 저장함.
- **Standalone Privacy**: 외부 API 연동 없이 내장된 주제 데이터를 활용하여 오프라인 환경에서도 끊김 없는 게임 진행이 가능하며 데이터 보안이 뛰어남.
