# PRD: 반려돌 키우기 (집중 세션 기록기)

## 1. 프로젝트 개요
스마트폰을 내려놓고 몰입하는 시간을 '반려돌'의 성장 에너지로 치환하여, 사용자의 집중력을 게이미피케이션 요소로 시각화해주는 디지털 펫 성장 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 스마트폰 사용을 줄이고 싶지만 의지가 약한 청소년 및 성인
- **문제 정의**: 단순히 시간을 기록하는 것보다, 내가 관리하는 대상(반려돌)이 성장하거나 퇴보하는 시각적 피드백을 통해 더 강력한 동기부여를 얻고자 함.

## 3. 핵심 기능 (Key Features)
- **집중 기반 성장**: '성장 시작' 버튼을 누른 후 스마트폰을 만지지 않으면 반려돌의 성장 포인트(Growth)가 상승함
- **자이로 센서 연동**: 기기를 흔들거나 각도를 크게 기울이면 반려돌이 깜짝 놀라며 성장 포인트가 깎이는 페널티 부여
- **레벨업 시스템**: 일정 포인트를 달성할 때마다 반려돌의 레벨이 오르고 외형적 보상(설명 문구 등) 제공
- **몰입 점수 기록**: 집중 세션 종료 시 최종 레벨과 성장 수치를 로컬에 저장

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Playful Design**: 귀여운 반려돌 캐릭터와 파스텔 톤의 부드러운 컬러 팔레트 사용
- **Dynamic Feedback**: 센서 감지 시 화면이 흔들리거나 빨간 테두리가 생기는 시각적 경고 효과
- **Chunky UI**: 직관적이고 큼직한 버튼 디자인과 둥근 카드 레이아웃

## 5. 기술 스택
- **Frontend**: HTML5, Vanilla JS, CSS (Animations, Keyframes)
- **Sensor API**: 브라우저 **DeviceOrientationEvent**를 활용한 기기 기울기 및 움직임 감지
- **Storage**: 브라우저 **localStorage**를 활용한 데이터 저장 (Standalone)

## 6. 사용자 흐름
1. 앱 접속 -> 2. 반려돌 상태 확인 -> 3. '성장 시작' 클릭 -> 4. 스마트폰을 평평한 곳에 내려놓고 집중 -> 5. 폰을 만지면 페널티 발생 -> 6. 집중 종료 후 성장 결과 확인

## 7. 데이터 관리 전략
- **Local Persistence**: `vcep_focus_session` 키를 사용하여 사용자의 누적 성장 포인트와 레벨 정보를 로컬에 안전하게 저장함.
- **Standalone Architecture**: 센서 데이터와 성장 로직이 모두 클라이언트 사이드에서 처리되며, 외부 서버(GAS 등) 통신 없이 독립적으로 구동됨.
