# PRD: 개인정보 동의서 요약기

## 1. 프로젝트 개요
복잡하고 긴 서비스 이용 약관이나 개인정보 처리 방침을 AI가 분석하여, 사용자가 반드시 알아야 할 핵심 내용(수집 항목, 보유 기간, 제3자 제공 여부 등)만 3줄로 요약해주는 서비스입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 긴 텍스트를 읽기 싫어하지만 개인정보 관리는 하고 싶은 고등학생
- **문제 정의**: 동의서는 너무 길고 법률 용어가 많아 읽기 어렵고, 이로 인해 내 데이터가 어디에 팔리거나 저장되는지 모른 채 동의함.

## 3. 핵심 기능 (Key Features)
- **텍스트 붙여넣기 분석**: 약관 내용을 복사해서 붙여넣으면 즉시 분석 시작
- **AI 3줄 요약**: 수집 항목, 보관 기간, 주의사항(제3자 제공 등)을 핵심 위주로 요약
- **독소 조항 탐지**: 사용자에게 불리할 수 있는 조항(예: 탈퇴 후에도 정보 보유)을 빨간색으로 강조
- **요약 리포트 저장**: 나중에 확인할 수 있도록 분석한 요약본을 개인 보관함에 저장

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Clean Typography**: 긴 글 분석 결과를 보여주는 가독성 높은 현대적 서체
- **Bento Grid**: 요약 내용, 주의 조항, 원문 대조를 그리드 형태로 배치
- **View Transitions**: 요약 버튼 클릭 시 '분석 중' 애니메이션과 함께 매끄러운 결과 전환

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **AI Integration**: Gemini API를 활용한 텍스트 요약 및 분석
- **Storage**: Browser IndexedDB (저장된 리포트 관리)

## 6. 사용자 흐름
1. 약관 원문 복사 -> 2. 앱에 붙여넣고 분석 클릭 -> 3. AI 3줄 요약 및 주의 조항 확인 -> 4. 리포트 저장 및 서비스 가입 결정

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 AI 텍스트 분석 웹앱 개발
- **실행 및 공유**: **Google AI Studio**에서 Gemini API를 활용하여 긴 약관을 실시간으로 요약 및 분석 결과 확인
- **데이터 저장**: 요약된 리포트는 **LocalStorage**에 저장하거나, 필요 시 **GAS**를 활용하여 **구글 스프레드시트**에 개인 보관함 형태로 저장
- **보안 및 권한**: 샌드박스 내에서 외부 API 호출 시 발생할 수 있는 CORS 이슈를 방지하기 위해 정형화된 요청 구조를 사용하고, API 응답 지연에 대비한 사용자 인터랙션(로딩바 등) 최적화
