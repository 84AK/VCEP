# PRD: 앱 권한 점검 체크리스트

## 1. 프로젝트 개요
새로운 앱을 설치할 때 요구하는 위치, 카메라, 연락처 등의 권한이 서비스 제공에 필수적인지, 과도한 정보 수집은 아닌지 사용자가 스스로 판단할 수 있도록 돕는 가이드 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 앱 설치 시 '모두 동의'를 무심코 누르는 중학생
- **문제 정의**: 앱이 왜 내 개인 정보가 필요한지 모른 채 권한을 허용하며, 이로 인해 의도치 않은 개인정보 유출 위험에 노출됨.

## 3. 핵심 기능 (Key Features)
- **권한별 위험도 안내**: 위치 정보, 마이크, 갤러리 접근 등 각 권한의 보안 등급(안전/주의/위험) 표시
- **유형별 필수 권한 가이드**: '지도 앱이면 위치 권한은 필수', '계산기 앱인데 카메라 권한은 불필요'와 같은 상황별 판단 기준 제공
- **개인정보 보호 설정 팁**: 아이폰/안드로이드 설정에서 권한을 다시 끄는 방법 안내
- **자가 진단 퀴즈**: 앱 권한 허용 여부를 결정하는 모의 테스트

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Bento Grid**: 권한 종류, 위험도 아이콘, 팁을 직관적인 그리드 레이아웃으로 배치
- **Interactive Checkbox**: 사용자가 체크할 때마다 실시간으로 보안 점수를 계산해주는 UI
- **Glassmorphism 2.0**: 각 권한 카테고리에 세련된 투명 배경 효과 적용

## 5. 기술 스택 제안
- **Frontend**: Vanilla JS, Tailwind CSS V4
- **State**: Browser LocalStorage (진단 기록)
- **Library**: Framer Motion (결과 노출 애니메이션)

## 6. 사용자 흐름
1. 설치하려는 앱의 유형 선택 -> 2. 앱이 요구하는 권한 선택 -> 3. 권한별 적절성 분석 결과 확인 -> 4. 보안 설정 가이드 실천

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Gemini Canvas**를 활용한 진단형 단일 HTML 앱 개발
- **실행 및 공유**: **Gemini Canvas** 또는 **Code Canvas**에서 즉시 실행 및 보안 점수 확인
- **데이터 저장**: 별도의 외부 저장 없이 **LocalStorage**를 활용하여 진단 기록 관리 (서버리스 방식)
- **보안 및 권한**: 외부 데이터를 호출하지 않는 순수 프론트엔드 로직으로 설계하여 CORS 에러와 브라우저 권한 충돌 이슈를 원천 방지
