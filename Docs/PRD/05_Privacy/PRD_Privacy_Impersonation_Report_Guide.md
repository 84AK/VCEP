# PRD: 온라인 사칭 신고 가이드

## 1. 프로젝트 개요
나의 사진이나 이름을 도용한 SNS 사칭 계정이나 온라인 사칭 범죄가 발생했을 때, 증거를 수집하고 각 플랫폼(인스타그램, 유튜브 등)에 신고하는 구체적인 절차를 안내하는 가이드 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 자신의 디지털 정체성이 도용되어 피해를 입은 중학생
- **문제 정의**: 사칭이 발생하면 당황하여 계정을 삭제해버리거나 대응을 포기하기 쉽지만, 정확한 신고 절차를 밟지 않으면 2차 피해가 발생할 수 있음.

## 3. 핵심 기능 (Key Features)
- **플랫폼별 신고 링크**: 인스타그램, 페이스북, 틱톡 등 주요 SNS의 사칭 신고 페이지 즉시 연결
- **증거 확보 스크린샷 팁**: 법적 효력을 갖추기 위해 반드시 포함해야 할 정보(URL, 날짜 등) 가이드
- **방송통신심의위원회 연계**: 민간 플랫폼 신고로 해결되지 않을 때 국가 기관에 심의 신청하는 방법 안내
- **마음 챙김 메시지**: 범죄 피해로 상처받은 마음을 위로하는 심리적 지지 콘텐츠

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Clean & Trustworthy Design**: 신뢰감을 주는 차분한 블루 톤의 인터페이스
- **Bento Grid**: 플랫폼 목록, 신고 절차, 법적 조언을 깔끔한 그리드로 레이아웃
- **Step-by-step Icons**: 복잡한 신고 과정을 하나씩 따라 할 수 있는 직관적인 단계별 아이콘

## 5. 기술 스택 제안
- **Frontend**: Vanilla JS, Tailwind CSS V4
- **Content**: Markdown 기반 플랫폼별 신고 매뉴얼
- **Library**: Framer Motion (가이드 단계 전환)

## 6. 사용자 흐름
1. 사칭이 발생한 플랫폼 선택 -> 2. 증거 수집 가이드에 따라 캡처 수행 -> 3. 공식 신고 링크로 이동 -> 4. 법적 조언 및 사후 대처 확인

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Gemini Canvas**를 활용한 매뉴얼 중심 단일 HTML 앱 개발
- **실행 및 공유**: **Gemini Canvas** 또는 **Code Canvas**에서 즉시 실행 및 단계별 신고 가이드 확인
- **데이터 저장**: 고정된 플랫폼별 신고 데이터 위주로 구성하며, 사용자 맞춤 기록은 저장하지 않는 '휘발성 가이드' 구조 채택
- **보안 및 권한**: 외부 공식 신고 페이지로의 리다이렉션이 샌드박스 정책에 의해 차단되지 않도록 `window.open` 핸들링 및 보안 링크 검증 로직 포함
