# PRD: 딥페이크 구별 학습 앱

## 1. 프로젝트 개요
AI가 생성한 가짜 영상(딥페이크)과 실제 영상을 비교하고, 딥페이크의 기술적 특징과 구별법을 학습하여 디지털 사기 및 성범죄 피해를 예방하는 교육용 퀴즈 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 디지털 미디어에 익숙하지만 정교한 가짜 영상에 취약한 중학생
- **문제 정의**: 딥페이크 기술이 정교해지면서 가짜 정보가 확산되고, 타인의 얼굴을 도용한 범죄가 늘어남에 따라 이를 판별하는 능력이 필수적임.

## 3. 핵심 기능 (Key Features)
- **진짜/가짜 판별 퀴즈**: 두 개의 영상을 보여주고 어떤 것이 AI가 만든 것인지 맞히는 게임
- **판별 포인트 가이드**: 부자연스러운 눈 깜빡임, 그림자 불일치 등 딥페이크의 기술적 허점 안내
- **피해 예방 매뉴얼**: 나를 도용한 딥페이크 발견 시 신고 절차 및 긴급 대처 방법 제공
- **최신 AI 트렌드 소식**: 딥페이크 기술의 발전과 이를 막기 위한 기술적 대응 현황 뉴스 제공

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Video-centric Layout**: 고해상도 영상을 선명하게 볼 수 있는 미디어 중심 디자인
- **Interactive Quizzes**: 정답 확인 시 폭죽 효과나 상세 해설 카드가 나타나는 역동적인 UI
- **Glassmorphism 2.0**: 영상 위에 정보를 띄워주는 세련된 반투명 오버레이 패널

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Media**: HTML5 Video Tag 및 고성능 비디오 플레이어 커스터마이징
- **Animations**: Framer Motion (결과 노출 효과)

## 6. 사용자 흐름
1. 학습 단계 선택 -> 2. 진짜/가짜 영상 판별 퀴즈 풀기 -> 3. 딥페이크 특징 해설 확인 -> 4. 피해 예방 수칙 복습

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 멀티미디어 교육용 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 환경에서 고해상도 비디오 퀴즈 및 판별 포인트 시각화 기능 확인
- **데이터 저장**: 퀴즈 점수 및 학습 완료 데이터는 **LocalStorage**에 저장하여 개인화된 피드백 제공
- **보안 및 권한**: 샌드박스 내 비디오 자동 재생 정책(`autoplay`) 및 미디어 권한 충돌을 방지하기 위해 사용자 클릭 기반 재생 로직 적용 및 CORS 최적화
