# PRD: 데이터 브로커 탐색기

## 1. 프로젝트 개요
나의 온라인 활동 데이터가 어떻게 수집되어 기업(데이터 브로커)들 사이에서 거래되는지 그 경로와 실태를 탐색하고, 데이터 주권의 중요성을 일깨워주는 교육용 시각화 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 데이터 주권과 디지털 경제에 관심이 있는 고등학생
- **문제 정의**: "내 데이터는 무료 서비스의 대가"라는 인식을 넘어, 개인정보가 하나의 상품으로 거래되는 과정이 불투명하여 사용자가 통제할 수 없음.

## 3. 핵심 기능 (Key Features)
- **데이터 거래 경로 시뮬레이션**: '앱 다운로드 -> 정보 수집 -> 데이터 브로커 판매 -> 타겟 광고'로 이어지는 여정 시각화
- **내 정보 가치 계산기**: 나의 연령, 성별, 취향 정보가 데이터 시장에서 약 얼마에 거래되는지 재미로 추산
- **글로벌 데이터 브로커 지도**: 전 세계의 주요 데이터 거래 기업들과 그들이 수집하는 정보 유형 안내
- **옵트아웃(Opt-out) 가이드**: 내 데이터 수집을 거부하거나 삭제를 요청할 수 있는 방법 학습

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Modern Infographics**: 복잡한 데이터 흐름을 직관적으로 보여주는 고품질 인포그래픽
- **Bento Grid**: 데이터 가치, 거래 경로, 대응 방안을 그리드 시스템으로 배치
- **Interactive Graphs**: 마우스 오버 시 데이터 거래의 세부 정보를 보여주는 동적 차트

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Visualization**: D3.js 또는 Chart.js
- **Animations**: Framer Motion (데이터 흐름 시뮬레이션)

## 6. 사용자 흐름
1. 내 데이터 가치 계산기 실행 -> 2. 데이터 거래 경로 시뮬레이션 시청 -> 3. 데이터 브로커의 실태 파악 -> 4. 데이터 주권 수호 가이드 확인

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 인포그래픽 중심 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 실행 환경에서 복잡한 데이터 거래 흐름 애니메이션 및 가치 계산 로직 확인
- **데이터 저장**: 별도의 사용자 데이터 수집 없이 프론트엔드 계산 로직만으로 동작하도록 설계하여 보안성 극대화
- **보안 및 권한**: 샌드박스 환경 내에서 복잡한 SVG/Canvas 애니메이션 렌더링 시 성능 저하가 발생하지 않도록 리소스 로딩 최적화 및 CORS 정책 준수
