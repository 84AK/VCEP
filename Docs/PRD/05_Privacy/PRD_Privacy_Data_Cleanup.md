# PRD: 내 데이터 어디 있나요?

## 1. 프로젝트 개요
사용자가 가입한 주요 서비스들이 어떤 개인정보를 보유하고 있는지 한눈에 정리하고, 잊고 있던 서비스의 개인정보 삭제를 요청하거나 계정 탈퇴를 돕는 개인 데이터 관리 센터입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 여러 웹사이트에 가입되어 있지만 관리가 되지 않는 고등학생
- **문제 정의**: 내가 어떤 사이트에 가입했는지, 그곳에 내 주민번호나 휴대폰 번호가 아직 남아있는지 파악하기 어려움.

## 3. 핵심 기능 (Key Features)
- **가입 서비스 리스트업**: 구글, 카카오 등 소셜 로그인을 통해 연결된 서비스 목록 확인 가이드
- **보유 데이터 요약**: 각 서비스가 일반적으로 수집하는 데이터 항목(이름, 이메일, 주소 등) 안내
- **탈퇴 가이드 및 링크**: '내정보 클린업' 서비스 등과 연계하여 가입한 사이트 탈퇴 링크 제공
- **데이터 주권 학습**: 나의 데이터를 기업이 어떻게 활용하는지, 삭제할 권리가 무엇인지 교육 콘텐츠 제공

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Bento Grid**: 내 가입 현황, 보안 등급, 탈퇴 가이드를 직관적인 그리드로 배치
- **Interactive Checklist**: 점검을 완료한 서비스들을 하나씩 체크하며 시각적 보상(성취감) 제공
- **Modern Typography**: 정보의 신뢰성과 명확성을 높이는 깔끔한 폰트 시스템

## 5. 기술 스택 제안
- **Frontend**: HTML5, Vanilla JS, Tailwind CSS V4
- **State**: Browser LocalStorage (점검 진행 현황 저장)
- **Content**: Markdown 기반의 서비스별 탈퇴 가이드 DB 구축

## 6. 사용자 흐름
1. 소셜 계정 연결 현황 확인 -> 2. 가입된 서비스 리스트 점검 -> 3. 불필요한 서비스 탈퇴 가이드 확인 -> 4. 데이터 삭제 완료 기록

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Gemini Canvas**를 활용한 가이드형 단일 HTML 앱 개발
- **실행 및 공유**: **Gemini Canvas** 또는 **Code Canvas**에서 개인 데이터 관리 현황 점검 및 공유
- **데이터 저장**: 점검한 서비스 리스트 및 탈퇴 완료 기록은 **LocalStorage**를 활용하여 브라우저 내 독립 저장
- **보안 및 권한**: 외부 사이트로의 링크 이동이 샌드박스 내에서 차단되지 않도록 `target="_blank"` 속성을 사용하고, 리소스 호출 시 발생할 수 있는 CORS 정책 준수
