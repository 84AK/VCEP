# PRD: 사진 메타데이터 확인기

## 1. 프로젝트 개요
스마트폰으로 촬영한 사진 파일 내부에 숨겨진 메타데이터(EXIF 정보)를 추출하여 촬영 위치, 시간, 기기 정보 등을 시각화해주고, 사생활 보호를 위해 이를 삭제할 수 있는 도구입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: SNS에 사진을 자주 올리는 중학생
- **문제 정의**: 사진 속에 우리 집 주소나 학교 위치 정보가 GPS 데이터로 포함되어 있다는 사실을 인지하지 못하고 공유하여 사생활 침해 위험이 있음.

## 3. 핵심 기능 (Key Features)
- **EXIF 데이터 추출**: 업로드한 사진의 GPS 좌표, 촬영 일시, 카메라 모델 등 상세 정보 표시
- **위치 기반 지도 표시**: 메타데이터의 좌표를 기반으로 사진이 찍힌 위치를 지도로 확인
- **개인정보 삭제(Stripping)**: 사진 속의 모든 위치 정보를 지우고 '깨끗한 이미지'로 다운로드
- **보안 등급 평가**: 사진에 포함된 정보의 양에 따라 보안 위험도(상/중/하) 평가

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Bento Grid**: 사진 미리보기, 상세 정보 리스트, 지도를 깔끔한 박스 형태로 배치
- **Glassmorphism 2.0**: 정보 패널에 깊이감을 주는 세련된 반투명 유리 효과
- **Drag & Drop UI**: 파일을 쉽고 빠르게 업로드할 수 있는 직관적인 영역 설계

## 5. 기술 스택 제안
- **Frontend**: Vanilla JS, Tailwind CSS V4
- **Library**: exif-js (메타데이터 추출), Leaflet/Kakao Maps (위치 시각화)
- **Image Processing**: HTML5 Canvas API (메타데이터 제거 및 재저장)

## 6. 사용자 흐름
1. 사진 업로드 -> 2. 숨겨진 메타데이터(위치 등) 확인 -> 3. '개인정보 삭제' 버튼 클릭 -> 4. 안전한 이미지로 저장 및 공유

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio** 또는 **Gemini Canvas**를 활용한 이미지 처리 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 실행 환경에서 사진의 EXIF 정보를 실시간으로 추출하고 지도에 위치 표시 기능 확인
- **데이터 저장**: 사진 파일은 서버에 저장하지 않는 'Client-side Processing' 방식을 고수하여 프라이버시 보호
- **보안 및 권한**: 샌드박스 환경 내에서 이미지 바이너리 데이터 접근 및 `input type="file"` 작동 시 보안 차단이 발생하지 않도록 표준 API 사용 및 예외 처리 로직 강화
