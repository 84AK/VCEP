# PRD: 개인정보 보호 수칙 체크앱

## 1. 프로젝트 개요
나의 디지털 보안 상태를 정기적으로 점검하고, '비밀번호 변경', '2단계 인증 설정', '로그인 기록 확인' 등 필수 개인정보 보호 수칙을 실천할 수 있도록 돕는 디지털 보안 매니저 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 보안 설정이 귀찮아서 미루는 고등학생
- **문제 정의**: 보안 수칙의 중요성은 알지만 실천이 번거롭고, 주기적인 관리가 되지 않아 해킹이나 정보 유출 사고에 취약함.

## 3. 핵심 기능 (Key Features)
- **보안 점수 대시보드**: 2단계 인증, 비밀번호 복잡도 등을 점검하여 현재 나의 보안 점수를 0~100점으로 표시
- **주간 보안 미션**: 'SNS 로그인 기기 정리하기', '오래된 앱 삭제하기' 등 매주 실천할 수 있는 작은 보안 미션 제공
- **보안 사고 리포트**: 최근 발생한 개인정보 유출 사고 사례와 예방책 뉴스 피드
- **정기 점검 알림**: 한 달에 한 번 주요 보안 설정을 다시 확인하도록 푸시 알림

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Bento Grid**: 보안 점수, 미션 현황, 뉴스 피드를 각각의 박스에 직관적으로 배치
- **Interactive Checkbox**: 보안 수칙 실천 시 실시간으로 점수가 오르는 다이내믹 UI
- **Glassmorphism 2.0**: 보안 등급에 따라 배경색이 변하는 투명 레이어 디자인

## 5. 기술 스택 제안
- **Frontend**: Vanilla JS, Tailwind CSS V4
- **State**: Browser LocalStorage (보안 점수 및 미션 완료 기록)
- **Library**: Canvas-confetti (보안 점수 상승 시 효과)

## 6. 사용자 흐름
1. 현재 보안 상태 진단 -> 2. 보안 점수 확인 -> 3. 추천 보안 미션 수행 -> 4. 점수 상승 확인 및 정기 점검 예약

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Gemini Canvas**를 활용한 체크리스트 기반 단일 HTML 앱 개발
- **실행 및 공유**: **Gemini Canvas** 또는 **Code Canvas**에서 나의 보안 점수를 실시간으로 확인하고 공유
- **데이터 저장**: 보안 수칙 실천 로그 및 정기 점검 예약 정보는 **LocalStorage**를 활용하여 브라우저 내 안전하게 보관
- **보안 및 권한**: 외부 데이터 전송을 배제하여 개인정보 유출 위험을 원천 차단하고, 샌드박스 내에서 알림 기능이 작동하도록 사용자 인터랙션 최적화
