# PRD: 쓰레기 줄이기 챌린지

## 1. 프로젝트 개요
1주일 또는 한 달 동안 특정 쓰레기(예: 일회용 컵, 비닐봉지) 배출을 제로로 만드는 도전 과제를 수행하고, 친구들과 공유하며 즐겁게 제로 웨이스트를 실천하는 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 실천 위주의 환경 활동을 선호하는 중학생
- **문제 정의**: 환경 보호의 필요성은 알지만 혼자 실천하기에는 동기부여가 부족하고, 구체적인 목표 없이 막연하게 느껴짐.

## 3. 핵심 기능 (Key Features)
- **챌린지 선택**: '일회용품 안 쓰기', '개인 텀블러 사용', '잔반 제로' 등 챌린지 중 선택
- **실천 인증샷 업로드**: 매일의 실천 모습을 사진으로 찍어 인증하고 스탬프 획득
- **진행률 바**: 챌린지 성공까지 남은 일수와 목표 달성률을 시각화
- **소셜 공유**: 나의 챌린지 현황을 멋진 이미지 카드로 만들어 SNS나 커뮤니티에 공유

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Gamified UI**: 레벨업, 뱃지, 스탬프 등 게임 요소를 적극 활용한 인터페이스
- **Bento Grid**: 내 챌린지 목록과 획득한 뱃지를 깔끔한 그리드로 구성
- **Interactive Buttons**: 클릭 시 터지는 애니메이션으로 인증의 재미 극대화

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Backend**: Firebase Storage (인증 사진 저장) 및 Firestore (챌린지 상태)
- **Animations**: CSS Keyframes 및 Confetti 효과

## 6. 사용자 흐름
1. 도전할 챌린지 선택 -> 2. 매일 실천 후 인증샷 등록 -> 3. 스탬프 및 포인트 획득 -> 4. 챌린지 완료 및 뱃지 수집

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 챌린지 관리 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 환경에서 사진 업로드 및 챌린지 진행 상태 실시간 확인
- **데이터 저장**: 챌린지 성공 기록 및 스탬프 데이터를 **GAS** 및 **구글 스프레드시트**에 저장
- **보안 및 권한**: 브라우저 샌드박스 내에서 카메라 및 파일 업로드 권한이 원활하게 작동하도록 `input type="file"` 표준 방식 준수 및 CORS 예외 처리 최적화
