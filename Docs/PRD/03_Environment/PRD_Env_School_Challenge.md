# PRD: 학교 환경 챌린지 앱

## 1. 프로젝트 개요
학급이나 동아리 단위로 분리배출, 에너지 절약 등 환경 보호 활동을 함께 실천하고 기록하며 학교 내 친환경 문화를 조성하는 그룹 실천 플랫폼입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 친구들과 함께 활동하며 성취감을 느끼고 싶은 중학생
- **문제 정의**: 개인의 노력은 작아 보일 수 있지만, 집단이 함께 움직였을 때의 임팩트를 시각화하여 더 큰 동기를 부여하고자 함.

## 3. 핵심 기능 (Key Features)
- **그룹 대항전**: 학급별 분리수거 점수, 전기 절약량 등을 비교하는 실시간 랭킹
- **공동 목표 달성 바**: "전교생이 1주일간 플라스틱 1,000개 줄이기"와 같은 큰 목표 설정 및 추적
- **활동 인증 게시판**: 그룹원들이 실천한 모습을 공유하고 응원하는 커뮤니티 공간
- **선생님 관리 모드**: 교사가 챌린지를 개설하고 우수 활동 학급에 보상을 지급하는 관리 기능

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Glassmorphism 2.0**: 학급별 랭킹 보드에 세련된 반투명 카드 UI 적용
- **Real-time Leaderboard**: 데이터 변화 시 실시간으로 순위가 변동되는 역동적인 애니메이션
- **Custom Icons**: 각 학급의 개성을 나타낼 수 있는 커스텀 아바타 및 아이콘 시스템

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Real-time**: Firebase Realtime Database 또는 Firestore
- **Charts**: Recharts (학급별 성과 비교 그래프)

## 6. 사용자 흐름
1. 소속 학급/그룹 가입 -> 2. 오늘의 환경 활동 인증샷 등록 -> 3. 우리 반 점수 및 전체 랭킹 확인 -> 4. 공동 목표 달성 현황 체크

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 그룹 대항 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 실행 환경을 통해 학급 간 실시간 랭킹 및 성과 공유
- **데이터 저장**: 학급별 포인트 및 목표 달성 현황을 **GAS**를 활용하여 **구글 스프레드시트** 클라우드 DB에 기록
- **보안 및 권한**: 실시간 대시보드 로딩 시 발생하는 CORS 이슈를 방지하기 위해 GAS 측의 응답 최적화와 함께, 샌드박스 보안 정책을 준수하는 데이터 페칭(Fetching) 모듈 구축
