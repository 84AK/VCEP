# PRD: 바코드 스캔 재활용 판별기

## 1. 프로젝트 개요
제품의 바코드를 카메라로 스캔하거나 제품명을 검색하면, 해당 제품의 구성 재질(플라스틱, 캔, 종이 등)과 정확한 분리배출 요령을 AI가 알려주는 스마트 환경 가이드입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 올바른 분리배출 방법을 배우고 싶은 중학생
- **문제 정의**: 제품마다 재질이 복잡하게 섞여 있어(예: 뚜껑은 플라스틱, 라벨은 비닐) 어떻게 버려야 재활용이 되는지 판단하기 어려움.

## 3. 핵심 기능 (Key Features)
- **바코드 스캔 인식**: 카메라 API를 활용해 실시간으로 제품 바코드 인식
- **상세 배출 가이드**: "라벨은 떼서 비닐로, 병은 깨끗이 씻어서 유리로"와 같은 단계별 안내
- **재활용 가능 점수**: 해당 제품이 얼마나 재활용하기 쉽게 만들어졌는지 점수화
- **대체 친환경 제품 추천**: 재활용이 어려운 제품 대신 사용할 수 있는 친환경 제품 제안

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Modern Search Bar**: 음성 인식과 카메라 스캔이 통합된 고성능 검색 바
- **Card-based Info**: 제품 정보를 깔끔한 카드 형태로 표시 (Glassmorphism 2.0 적용)
- **High-resolution Icons**: 분리배출 종류를 직관적으로 알 수 있는 고품질 아이콘 사용

## 5. 기술 스택 제안
- **Frontend**: Vanilla JS, Tailwind CSS V4
- **Camera**: QuaggaJS 또는 ZXing (바코드 스캔 라이브러리)
- **Data**: 공공데이터포털 또는 커스텀 재활용 DB 연동

## 6. 사용자 흐름
1. 앱 내 카메라 실행 -> 2. 바코드 스캔 -> 3. 제품 재질 및 배출 방법 확인 -> 4. 가이드에 따라 분리배출 실천

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 카메라 기반 웹앱 개발
- **실행 및 공유**: **Google AI Studio**의 라이브 미리보기 환경에서 실시간 바코드 스캔 및 데이터 검색 기능 확인
- **데이터 저장**: 제품별 재활용 데이터베이스(DB)를 **구글 스프레드시트**에 구축하고 **GAS**를 통해 호출
- **보안 및 권한**: 샌드박스 환경에서 **카메라(MediaDevices.getUserMedia) 권한**이 차단되지 않도록 강력한 예외 처리 로직을 추가하고, HTTPS 환경 보장 전략 수립
