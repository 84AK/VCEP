# PRD: 환경 포인트 게임

## 1. 프로젝트 개요
친환경 행동을 실천할 때마다 가상의 환경 포인트(Eco-Points)를 획득하고, 이를 통해 자신만의 가상 섬이나 숲을 가꾸는 게이미피케이션 환경 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 게임을 즐기며 보상을 얻는 것을 좋아하는 중학생
- **문제 정의**: 환경 보호가 지루하거나 의무적인 활동이 아니라, 재미있는 놀이로 인식될 수 있도록 유도함.

## 3. 핵심 기능 (Key Features)
- **포인트 적립 미션**: '텀블러 사용 인증', '걷기 실천' 등 일일 미션 완료 시 포인트 지급
- **가상 세계 꾸미기**: 획득한 포인트로 나무를 심고, 동물을 불러오고, 깨끗한 에너지를 생산하는 기지를 구축
- **레벨 및 진화**: 환경 활동이 누적됨에 따라 내 가상 세계가 점점 더 아름답고 풍요롭게 변화
- **친구 섬 방문**: 친구의 가상 세계를 구경하고 서로 포인트(에너지)를 선물하는 소셜 기능

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **3D Isometric Graphics**: 입체감 있는 가상 세계를 시각화한 그래픽 디자인
- **Lottie Animations**: 나무가 자라거나 동물이 움직이는 인터랙티브 애니메이션
- **Floating Buttons**: 조작이 편리한 부유형 액션 버튼 및 직관적인 아이콘

## 5. 기술 스택 제안
- **Frontend**: Vanilla JS, Three.js (3D 시각화) 또는 CSS 3D
- **Animations**: Framer Motion, Lottie
- **State**: Redux 또는 Zustand (성장 데이터 관리)

## 6. 사용자 흐름
1. 일일 환경 미션 확인 및 수행 -> 2. 포인트 획득 -> 3. 가상 세계(섬) 확장 및 장식 -> 4. 친구들과 성장 결과 공유

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio** 또는 **Gemini Canvas**를 활용한 게이미피케이션 웹앱 개발
- **실행 및 공유**: **Google AI Studio**에서 가상 섬 시뮬레이션 동작 확인 및 결과 공유
- **데이터 저장**: 사용자의 레벨, 보유 포인트, 섬 구성 데이터를 **GAS**를 통해 **구글 스프레드시트**에 저장 및 호출
- **보안 및 권한**: 3D 그래픽(Three.js 등) 라이브러리 사용 시 샌드박스 환경 내 GPU 가속 권한 문제를 사전 체크하고, GAS 요청 시 브라우저 보안 차단을 방지하는 데이터 규격화 적용
