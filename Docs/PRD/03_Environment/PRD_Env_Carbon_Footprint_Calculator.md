# PRD: 탄소 발자국 계산기

## 1. 프로젝트 개요
나의 이동 수단, 식습관, 냉난방 방식 등 일상 생활 데이터를 입력하여 배출되는 이산화탄소 양을 계산하고, 이를 나무 심기 개수 등으로 변환해 보여주는 탄소 중립 실천 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 환경 문제의 수치를 정확히 파악하고 대안을 찾고 싶은 고등학생
- **문제 정의**: 기후 위기의 심각성은 알지만 나의 일상이 지구 온난화에 얼마나 기여하는지 구체적인 수치(탄소량)로 인지하지 못함.

## 3. 핵심 기능 (Key Features)
- **탄소 계산기**: 식사(육류 위주 vs 채식), 교통(대중교통 vs 승용차) 등 문항별 선택
- **실시간 결과 시각화**: 입력 즉시 나의 연간 예상 탄소 배출량을 수치와 그래프로 산출
- **직관적 비교 지표**: 탄소량을 '심어야 할 소나무 개수'나 '지구를 몇 바퀴 도는 비용' 등으로 환산
- **저탄소 대안 제시**: "현재 습관에서 소고기 식단을 주 1회 줄이면 소나무 10그루를 심는 효과가 있습니다"와 같은 제안

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Bento Grid**: 계산 결과, 비교 지표, 개선 제안을 박스 그리드로 레이아웃
- **High-contrast Typography**: 핵심 수치를 강조하는 굵고 명확한 타이포그래피
- **Modern Input Components**: 슬라이더와 세련된 선택 버튼을 활용한 데이터 입력 방식

## 5. 기술 스택 제안
- **Frontend**: HTML5, Vanilla JS, Tailwind CSS V4
- **Calculation Logic**: 탄소 배출 계수(IPCC 기준 등)를 적용한 알고리즘 탑재
- **Visualization**: Chart.js (배출 항목별 비중 분석)

## 6. 사용자 흐름
1. 생활 습관 설문 응답 -> 2. 탄소 발자국 총량 확인 -> 3. 나무 개수 등 비교 지표 열람 -> 4. 맞춤형 탄소 감축 계획 확인

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Gemini Canvas**를 활용한 단일 HTML 계산기 앱 개발
- **실행 및 공유**: **Gemini Canvas** 또는 **Code Canvas**에서 즉시 실행 및 계산 결과 확인
- **데이터 저장**: 별도의 클라우드 저장 없이 **LocalStorage**를 활용하여 이전 계산 기록 관리 (간편 서버리스 구조)
- **보안 및 권한**: 외부 API 호출이 없는 순수 로직으로 설계하여 CORS 에러와 브라우저 보안 권한 이슈를 원천적으로 방지
