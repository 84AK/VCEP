# PRD: 우리 동네 기후 변화 기록

## 1. 프로젝트 개요
우리 동네에서 관찰되는 이상 기후 현상(갑작스러운 폭우, 폭염, 평소보다 이른 꽃 개화 등)을 사용자가 직접 사진과 텍스트로 기록하고 지도로 공유하는 시민 과학 환경 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 기후 위기의 현장을 목격하고 기록하고 싶은 고등학생
- **문제 정의**: 기후 변화는 전 지구적 문제지만, 정작 내가 사는 지역의 구체적인 변화 양상을 기록하고 공유할 채널이 부족함.

## 3. 핵심 기능 (Key Features)
- **위치 기반 기록(Geo-tagging)**: 이상 기후 현상을 사진으로 찍어 현재 위치에 핀으로 등록
- **기후 맵(Climate Map)**: 다른 사용자들이 등록한 동네의 기후 위기 현황을 지도상에서 실시간 확인
- **과거 데이터 비교**: 현재의 현상이 과거 평균 데이터와 얼마나 다른지 통계 수치 제공
- **알림 및 경보**: 특정 지역에 이상 기후 제보가 집중될 경우 인근 사용자들에게 주의 알림

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Map-centric Interface**: 정보를 한눈에 볼 수 있는 인터랙티브 지도 디자인
- **Glassmorphism 2.0**: 지도 위에 정보를 띄워주는 세련된 반투명 팝업 카드
- **Scroll-driven Animations**: 과거와 현재의 기후 데이터를 비교할 때 사용하는 타임라인 애니메이션

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Maps**: Kakao Maps API 또는 Google Maps
- **Backend**: Firebase Firestore (실시간 제보 저장 및 공유)

## 6. 사용자 흐름
1. 이상 기후 현상 목격 -> 2. 사진 촬영 및 태그(폭염, 폭우 등) 선택 -> 3. 위치 기반 제보 등록 -> 4. 동네 기후 맵에서 전체 현황 탐색

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 지도/제보 기반 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 실행 환경에서 실시간 기후 맵 동작 확인 및 링크 공유
- **데이터 저장**: 사용자의 제보 내용(위치, 사진 설명)을 **GAS** 및 **구글 스프레드시트**를 통해 클라우드에 공유 DB로 구축
- **보안 및 권한**: 샌드박스 내 `Geolocation API` 및 카메라 접근 권한 차단을 방지하기 위해 사용자 승인 가이드를 UI에 포함하고, GAS 통신 시 CORS 정책을 완벽히 준수하도록 설정
