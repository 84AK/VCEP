# PRD: 오늘의 쓰레기 기록 앱

## 1. 프로젝트 개요
하루 동안 자신이 배출한 쓰레기의 종류와 양을 간단하게 기록하고 시각화하여, 일상 속 쓰레기 배출 습관을 인지하고 줄여나갈 수 있도록 돕는 환경 가계부 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 환경 보호에 관심이 생기기 시작한 중학생
- **문제 정의**: 무심코 버리는 쓰레기가 하루에 얼마나 되는지 체감하지 못하며, 분리배출에 대한 구체적인 인식이 부족함.

## 3. 핵심 기능 (Key Features)
- **쓰레기 간편 기록**: 일반쓰레기, 플라스틱, 종이, 비닐 등 카테고리별 배출 개수/무게 입력
- **배출 데이터 대시보드**: 일일/주간 쓰레기 발생량을 Bento Grid 레이아웃으로 시각화
- **재활용 가이드 연동**: 기록 시 해당 품목의 올바른 분리배출 방법 팁 제공
- **감소 목표 설정**: 지난주 대비 쓰레기 배출량을 10% 줄이는 등의 도전 목표 설정

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Eco-Friendly Palette**: 녹색과 대지의 색상을 활용한 차분하고 자연 친화적인 테마
- **Glassmorphism 2.0**: 쓰레기 통계 카드를 세련된 반투명 유리 효과로 디자인
- **Scroll-driven Animations**: 스크롤 시 쓰레기 양이 줄어드는 애니메이션 효과로 성취감 고취

## 5. 기술 스택 제안
- **Frontend**: Vanilla JS, Tailwind CSS V4
- **Charts**: Chart.js (일일 배출량 추이)
- **Storage**: Browser LocalStorage 또는 GAS 연동

## 6. 사용자 흐름
1. 쓰레기 발생 시 앱 접속 -> 2. 종류 및 양 선택 -> 3. 저장 및 통계 대시보드 확인 -> 4. 맞춤형 분리배출 팁 확인

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Gemini 채팅**을 통한 단일 HTML 앱 구현
- **실행 및 공유**: **Code Canvas** 에디터에서 기록 및 대시보드 시각화 기능 테스트
- **데이터 저장**: 배출한 쓰레기의 종류와 양 데이터를 **GAS**를 활용하여 **구글 스프레드시트**에 영구 저장
- **보안 및 권한**: GAS 요청 시 샌드박스 환경의 네트워크 지연이나 CORS 차단을 방지하기 위해 경량화된 JSON 데이터 구조 사용
