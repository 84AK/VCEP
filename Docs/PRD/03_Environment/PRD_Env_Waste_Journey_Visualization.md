# PRD: 쓰레기 여정 시각화 앱

## 1. 프로젝트 개요
내가 버린 쓰레기가 수거되어 선별장, 재활용 공장 혹은 소각장으로 가는 과정을 지도와 인포그래픽으로 시각화하여, 쓰레기 처리 시스템의 현실을 이해하도록 돕는 교육용 앱입니다.

## 2. 타겟 사용자 및 문제 정의
- **타겟**: 환경 문제의 구조적 원인을 탐구하고 싶은 고등학생
- **문제 정의**: 쓰레기를 버리는 행위로 끝나는 것이 아니라, 그 이후의 처리 과정이 환경에 어떤 영향을 미치는지에 대한 시야가 부족함.

## 3. 핵심 기능 (Key Features)
- **가상 추적 시뮬레이션**: 특정 품목(예: 페트병)을 선택하면 수거부터 최종 처리까지의 경로를 애니메이션으로 구현
- **지역별 처리 통계**: 우리 동네의 재활용률, 소각량, 매립량 데이터를 지도로 표시
- **환경 비용 계산기**: 쓰레기 한 톤을 처리할 때 발생하는 탄소 배출량 및 경제적 비용 산출
- **퀴즈 및 리포트**: 쓰레기 여정을 체험한 후 배운 내용을 정리하는 퀴즈 기능

## 4. UI/UX 디자인 원칙 (2026 Trend)
- **Map-centric Design**: 지도를 배경으로 한 직관적인 정보 배치
- **Bento Grid**: 통계 지표와 시뮬레이션 컨트롤러를 그리드 형태로 구성
- **Smooth Transitions**: 경로를 따라 화면이 이동할 때 부드러운 카메라 무빙 효과

## 5. 기술 스택 제안
- **Frontend**: React, Tailwind CSS V4
- **Animation**: Lottie (쓰레기 이동 애니메이션) 또는 CSS Keyframes
- **Maps**: Mapbox 또는 Leaflet (지도 데이터 시각화)

## 6. 사용자 흐름
1. 품목 선택 -> 2. 수거 경로 및 처리 과정 시뮬레이션 시청 -> 3. 환경 데이터 리포트 열람 -> 4. 퀴즈를 통한 학습 마무리

## 7. 구현 및 데이터 관리 전략
- **개발 환경**: **Google AI Studio**를 활용한 고성능 애니메이션/시각화 웹앱 개발
- **실행 및 공유**: **Google AI Studio** 또는 **Gemini Canvas**에서 시각화 시나리오 실시간 실행 및 공유
- **데이터 저장**: 정적 시뮬레이션 데이터 위주로 구성하며, 퀴즈 결과 등은 **LocalStorage**를 활용하여 저장
- **보안 및 권한**: 외부 지도 타일이나 애니메이션 라이브러리 로딩 시 CORS 정책에 의해 차단되지 않도록 CDN 선택 및 리소스 최적화 진행
