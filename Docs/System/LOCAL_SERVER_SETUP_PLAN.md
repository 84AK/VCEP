# 📋 로컬 서버 구축 및 공유 계획 (Blueprint)

이 문서는 실습실 또는 교실 환경에서 인터넷 연결 없이도 모든 학생이 동일한 프로젝트에 접속할 수 있도록 로컬 서버를 구축하고 공유하는 구체적인 절차를 정의합니다.

## 1. 하드웨어 구성 (Hardware Setup)
*   **호스트(Host):** 교사(선생님)의 컴퓨터. 실습 전체의 메인 서버 역할을 수행합니다.
*   **네트워크(Network):** 교실 내 유/무선 공유기. (외부 인터넷 연결은 필요 없으나, 기기 간의 통신을 위해 필요합니다.)
*   **클라이언트(Client):** 학생들의 노트북, 태블릿 또는 스마트폰.

## 2. 서버 실행 방법 (Server Execution)
*   **추천 방법 (npx):** 프로젝트 루트 디렉토리에서 아래 명령어를 실행합니다.
    ```bash
    npx serve -l 5000
    ```
*   **파이썬 활용:** 별도의 설치가 어려운 경우 내장 파이썬을 활용합니다.
    ```bash
    python3 -m http.server 5000
    ```

## 3. 실전 공유 프로세스 (Step-by-Step)
1.  **IP 주소 확인:** 호스트 컴퓨터에서 `ifconfig` (Mac) 또는 `ipconfig` (Windows)를 입력하여 내부 IP(예: `192.168.0.x`)를 확인합니다.
2.  **접속 주소 생성:** 확인된 IP와 설정한 포트 번호를 조합합니다. (예: `http://192.168.0.10:5000`)
3.  **방화벽 설정:** 호스트 컴퓨터의 방화벽에서 해당 포트(5000)의 인바운드 규칙을 일시적으로 허용하여 학생들의 접속을 가능하게 합니다.
4.  **QR 코드 배포:** 주소를 직접 입력하기 번거로운 경우, 온라인/오프라인 QR 생성기를 통해 주소를 QR 코드로 변환하여 칠판이나 화면에 게시합니다.
5.  **접속 확인:** 학생들이 브라우저 주소창에 해당 주소를 입력하여 대시보드(index.html)가 정상적으로 나타나는지 확인합니다.

## 4. 운영 팁 (Management)
*   **수업 종료 후:** 서버 프로세스(터미널)를 반드시 종료하여 불필요한 리소스 낭비와 보안 노출을 방지합니다.
*   **데이터 관리:** 실습 중 발생하는 데이터는 브라우저의 `localStorage`에 저장되므로, 학생이 기기를 바꿔서 접속할 경우 이전 데이터가 연동되지 않음을 사전에 안내합니다.
