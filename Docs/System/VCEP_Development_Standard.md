# 💎 VCEP 앱 개발 표준 가이드 (2026)

이 문서는 VCEP(VibeCoding Education Project)의 40개 앱을 개발할 때 일관된 사용자 경험(UX)과 고품질의 UI를 보장하기 위한 가이드라인입니다. 1단계 스마트폰 과사용 예방 프로젝트의 수정 및 개선 사항을 바탕으로 작성되었습니다.

---

## 1. 디자인 원칙 (Aesthetics & UI)

### 🎨 시각적 스타일
- **Theme**: Sleek Dark Mode 또는 Glassmorphism 2.0을 기본으로 합니다.
- **Glassmorphism**: `backdrop-filter: blur(12px);`, `background: rgba(255, 255, 255, 0.1);`, `border: 1px solid rgba(255, 255, 255, 0.1);`를 활용하여 깊이감을 줍니다.
- **Typography**: 제목은 `Outfit` (800), 본문은 `Inter` (400/600) 폰트를 사용하여 프리미엄 느낌을 유지합니다.
- **Colors**: 원색 대신 채도가 조절된 현대적인 컬러 팔레트(예: Indigo #6366f1, Rose #f43f5e, Emerald #10b981)를 사용합니다.

### 📊 시각화 표준
- **Circular Progress**: 단순히 테두리를 돌리는 방식이 아닌, `conic-gradient`를 사용하여 실제 달성량을 채우는 방식을 사용합니다.
- **Charts (Chart.js)**: 
    - 데이터 점이 잘리지 않도록 `layout: { padding: 20 }` 설정을 반드시 포함합니다.
    - 축의 최댓값은 실제 최고 데이터보다 10~20% 여유 있게 설정합니다 (`suggestedMax` 활용).

---

## 2. 기능 및 인터랙션 원칙 (UX & Logic)

### ✍️ 참여형 인터페이스
- **No Static Display**: 단순히 데이터를 보여주는 것에 그치지 말고, 반드시 사용자가 자신의 데이터를 입력하거나 선택할 수 있는 **입력 폼(Input Form)**을 제공합니다.
- **Explicit Action**: 체크박스 클릭 시 자동 저장되는 방식보다는, 모든 과정을 마친 후 **[기록 저장하기]** 또는 **[오늘의 루틴 완료]**와 같은 명확한 제출 버튼을 제공하여 '작업의 완료'를 인지시킵니다.

### 🤖 실시간 피드백
- **AI Analysis**: 사용자가 데이터를 입력하거나 작업을 완료하면, 그 수치에 반응하는 **동적 메시지(AI 인사이트)**를 즉시 노출합니다.
- **Loading State**: 데이터 전송 시 버튼 텍스트를 "저장 중..."으로 변경하고, 완료 후 "저장 완료! 😴"와 같은 시각적 피드백을 줍니다.

---

## 3. 백엔드 및 대시보드 연동 (System)

### ☁️ GAS(Google Apps Script) 연동
- 모든 앱은 `doPost(e)` 함수를 통해 데이터를 전송하며, 전송 방식은 `no-cors` 모드를 기본으로 합니다.
- `index.html`의 `appData` 객체에는 다음 항목이 정규화되어 포함되어야 합니다:
    - `columns`: 스프레드시트의 열 구성 정보 (표 형식으로 노출됨)
    - `gasCode`: 실제 `Docs/GAS/` 폴더의 코드와 100% 일치하는 코드

### 📂 모달 시스템 가이드
- 모달이 처음 열릴 때 **'설명' 탭이 활성화(파란색 밑줄)**되도록 `switchTab('info')` 로직을 보장해야 합니다.
- 소스 코드 보기 탭에서는 실제 앱의 HTML/JS 전문을 불러와 복사 가능하게 제공합니다.
