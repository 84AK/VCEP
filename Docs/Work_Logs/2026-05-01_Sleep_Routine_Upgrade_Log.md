# 수면 유도 양 떼 목장 - 전면 고도화 로그

**기록 일자**: 2026-05-01
**작성자**: Doc - 서기
**목적**: 단순했던 '수면 유도 양 떼 목장'(`sleep_routine.html`) 앱을 실제 수면에 도움을 주는 고도화된 인터랙티브 웰니스 앱으로 재구축한 내역 기록.

## 1. 수면 유도 기능(Sleep Induction) 구현 내역

### 1.1 🌙 4-7-8 호흡 가이드 (의학적 수면 기법)
*   우측 상단의 달(`moon`) UI를 활용하여 시각적인 호흡 메트로놈을 구현함.
*   자바스크립트의 비동기 타이머 로직을 이용해 `들이마시기(4초) -> 참기(7초) -> 내쉬기(8초)` 사이클을 무한 반복함.
*   CSS `transform: scale()`과 `transition`을 세밀하게 조절하여, 폐가 부풀어 오르는 듯한 자연스러운 애니메이션 적용.

### 1.2 🎧 Web Audio API 기반 ASMR (백색 소음)
*   무거운 외부 `.mp3` 파일 없이, 자바스크립트 `AudioContext`의 랜덤 노이즈 버퍼를 활용해 자체적으로 백색 소음을 생성함.
*   `BiquadFilterNode(lowpass)`를 적용하여 날카로운 소리를 깎아내고, `setInterval`로 주파수 값을 지속해서 변경하여 **밤바람이나 파도 소리**와 흡사한 편안한 ASMR을 연출.

### 1.3 🌌 점진적 다크 디밍 (Dark Dimming)
*   사용자가 앱을 켜두고 잠들 수 있도록 화면 전체를 덮는 `#dimmer` 오버레이를 추가함.
*   `setInterval`을 통해 1분마다 검은색 오버레이의 투명도(opacity)를 5%씩 높여 눈의 피로를 최소화.

### 1.4 🐑 다채로운 양 떼 & 양 세기 텍스트 효과
*   양 이모지를 다양화(`🐑`, `🐏`)하고 폰트 사이즈와 애니메이션 속도(8~14초)를 난수화하여 단조로움을 탈피.
*   양이 화면 중앙 펜스를 뛰어넘을 때쯤 `showCountText()` 함수를 호출하여, 하늘에 "양 N마리..."라는 텍스트가 스르륵(`floatUp`) 몽환적으로 나타났다 사라지는 최면 효과 적용.

## 2. 인터랙티브 페널티(Penalty) 기능 강화
*   **문제**: 사용자가 무의식중에 폰을 만질 때 즉각적인 제재가 부족했음.
*   **해결**:
    1.  **플래시 효과**: 화면이 번쩍(`flashAnim`) 밝아져 수면 무드를 깸.
    2.  **오디오 중단**: ASMR 오디오가 일시 정지(`audioCtx.suspend()`)됨.
    3.  **양 도망가기**: 화면에 있던 양들이 도망가는 이모지(`🐏💨`)로 변하며 1.5초 만에 빛의 속도로 화면 밖으로 뛰쳐나감.
    4.  **페널티 누적**: 다크 디밍 수치가 일정 부분 초기화되어 다시 화면이 밝아짐.

## 3. 구조적 변경 사항
*   **시작 모달 추가**: 브라우저 정책상 사용자 상호작용(Gesture) 없이 Audio 재생이 불가능하므로, `intro-overlay`를 추가하여 "수면 모드 시작하기" 버튼을 눌렀을 때 모든 오디오와 애니메이션이 시작되도록 진입 구조를 개편함. 

## 4. 결과
*   단순한 애니메이션 뷰어에서 **시각, 청각, 호흡**을 모두 통제하는 실용적인 웰니스/디톡스 앱으로 완벽하게 탈바꿈함.
