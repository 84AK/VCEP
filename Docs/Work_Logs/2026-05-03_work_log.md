## 🛠️ 구현 및 수정 내용
### 1. 로컬 수업 환경 구축 가이드 수립
- **상담 내용:** `npx serve` 또는 `python -m http.server`를 이용한 로컬 IP 기반 공유 방식 제안.
- **해결 방안:** 동일 Wi-Fi 환경에서 선생님 컴퓨터를 서버로 활용하여 학생들에게 접속 주소(QR 코드 등) 제공.

### 2. 오프라인(No-Internet) 수업 전략 수립
- **전략:** USB/AirDrop을 통한 프로젝트 폴더 직접 배포 방식 및 Ad-hoc 네트워크 활용 제안.
- **기술적 과제:** 외부 CDN(Tailwind, Google Fonts 등) 의존성을 제거하고 로컬 리소스로 교체하는 '오프라인 최적화' 필요성 확인.

### 3. 홈 화면 메뉴 업데이트 (`index.html`)
- **수정 사항:** 상단 내비게이션 바에 '앱 플래너'(`apps/app_planner.html`) 링크 추가.
- **효과:** 앱 기획 및 설계 단계로의 접근성 대폭 향상.

### 4. CSS 호환성 개선 (`sleep_correlation.html`, `tutorial_hub.html`)
- **수정 사항:** `background-clip` 속성에 표준 명세 추가.
- **해결 내용:** `-webkit-background-clip: text;`만 사용하던 코드에 표준 속성인 `background-clip: text;`를 병기하여 최신 브라우저 호환성 확보. (`sleep_correlation.html`, `tutorial_hub.html` 공통 적용)
