# 작업 로그 (Work Log) - 2026년 5월 4일

## 1. 프로젝트 개요
- **프로젝트 명**: 철벽 AI의 마음을 녹여라! (Interactive Dating Sim for Prompt Engineering)
- **주요 목표**: 비주얼 노벨 인터랙션과 프롬프트 엔지니어링 교육의 결합 및 UX 완성도 향상.

## 2. 주요 수정 및 구현 사항 (Implementation Log)

### A. 대화 시스템 (Dialogue System)
- **순차적 대화 출력**: 클릭 시 대화가 한 줄씩 나오는 비주얼 노벨 방식 로직 구현 (`advanceDialogue`, `playDialogue`).
- **화자 구분 UI**: 플레이어('나')와 캐릭터('아이리스/카일')의 텍스트 스타일과 컬러를 구분하여 가독성 증대.
- **애니메이션**: 대화창 전환 및 캐릭터 표정 변화 시 부드러운 페이드 효과 적용.

### B. UI/UX 레이아웃 최적화
- **HUD 재배치**: 호감도 바와 스테이지 정보를 상단으로 이동시켜 우측 입력 패널과의 겹침 문제 해결.
- **반응형 가이드**: 스테이지별 구체적 행동 지침(Action Guide)을 제공하는 지능형 안내 시스템 구축.
- **입력 유도**: 유저 턴에 입력창 영역이 푸른색으로 맥박(Pulse)치도록 시각적 유도 추가.

### C. 프롬프트 교육 강화
- **스테이지별 서사 강화**: RCTF, Few-shot, Temperature, Negative Prompt 각 단계에 풍부한 스토리 배경(Bridge Story) 추가.
- **실시간 대사 미리보기**: Temperature 슬라이더 조작 시 감정 상태에 따른 대사 변화를 즉시 확인 가능하도록 구현.
- **모범 사례(Best Practice) 제공**: 미션 완료 후 실제 활용 가능한 한국어 모범 프롬프트 예시 노출.

### D. 엔딩 시스템
- **전용 엔딩 스크린**: `alert` 방식에서 벗어나 서사적 요약과 프롬프트 성적표(S~A등급)를 포함한 고퀄리티 결과 화면 구현.

## 3. 에러 발생 및 해결 내역 (Troubleshooting)
- **에러**: 대화 출력 도중 'NEXT' 인디케이터와 사이드바 가이드가 겹쳐 보이거나 사라지는 현상.
  - **해결**: `dialogueCallback` 존재 여부에 따른 분기 로직을 정교화하여 마지막 지문 출력 시 상황에 맞는 인디케이터만 노출되도록 수정.
- **에러**: 스테이지 1에서 문맥(Context) 입력이 구체적임에도 '뻔하다'는 피드백이 반복됨.
  - **해결**: 글자 수 기준 완화(20자 -> 15자) 및 캐릭터 피드백을 구체적 가이드(날씨, 소리 등 추가 제안) 형식으로 변경.

## 4. 향후 과제
- **모바일 최적화**: 현재 레이아웃의 데스크탑 중심 설계를 모바일 환경에서도 쾌적하게 사용할 수 있도록 미디어 쿼리 보강 필요.
- **시나리오 확장**: 더 다양한 인물과 갈등 상황을 추가하여 프롬프트 엔지니어링의 다양한 활용 사례(코딩, 창작 등) 교육.
