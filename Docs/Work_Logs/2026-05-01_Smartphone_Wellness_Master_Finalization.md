## 2. 주요 수정 및 구현 사항
### [마스터 앱 & 데이터 연동]
- **통합 대시보드 구축**: 8개의 미니 앱을 Iframe으로 로드하고 실시간 상태를 Bento Grid로 시각화하는 `smartphone_wellness_master.html` 개발.
- **GAS 백엔드 v2**: 시트 이름을 한국어('시간 도둑', '반려돌 키우기' 등)로 자동 생성하도록 GAS 코드 업그레이드.
- **실시간 동기화 시스템**: `localStorage` Proxy와 `postMessage` API를 결합하여 앱 데이터 변경 즉시 클라우드와 대시보드에 반영되도록 개선.

### [미니 앱 개선]
- **양 떼 목장 (Sleep Routine)**: 저장 주기를 '매 마리당'으로 단축하고 화면 터치 시 즉시 저장되도록 로직 수정.
- **도파민 수사대 (Pattern Analyzer)**: 결과 데이터가 저장되지 않던 문제를 해결하고 MBTI 결과를 클라우드에 연동.
- **공통 싱크 스크립트 주입**: 모든 8개 앱에 마스터 앱과 통신하기 위한 동기화 도우미 스크립트 적용.

### [교육 및 문서화]
- **메인 페이지 업그레이드**: `index.html` 모달 창에 **GAS 소스코드 탭**을 추가하여 사용자가 백엔드 코드를 바로 확인할 수 있게 함.
- **교육 가이드 제작**: 기획 도구(`app_planner.html`)와 PRD 분석을 포함한 **'기획 우선 개발'** 교육 가이드(`VCEP_Smartphone_Wellness_Maker_Guide.md`) 작성.

## 3. 발생했던 문제 및 해결 (Troubleshooting)
- **문제**: Iframe 내부에서 `localStorage` 변경 시 부모 창의 `storage` 이벤트가 안정적으로 발생하지 않음.
- **해결**: `postMessage`를 사용하여 자식 창(Iframe)이 부모 창(Master)에 명시적으로 신호를 보내는 방식으로 전환하여 100% 동기화 성공.
- **문제**: GAS 시트 이름이 영어(Category Key)로 생성되어 가독성이 떨어짐.
- **해결**: 마스터 앱과 GAS 백엔드 양측에 `nameMap` 테이블을 구축하여 한국어로 시트가 생성되도록 처리.
