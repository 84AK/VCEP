# Work Log: 공감 대화 연습 '마음의 온도' 앱 개발 및 UI 고도화

**날짜:** 2026-05-02
**작업자:** Antigravity (Architect, Worker, Solver, Designer, Scribe)

## 1. 개요
비폭력 대화(NVC) 원칙을 기반으로 한 공감 교육 앱 '마음의 온도'의 핵심 기능을 구현하고, 사용자 피드백을 반영하여 캐릭터 중심의 감성적인 UI로 고도화함.

## 2. 주요 구현 내용
- **4컷 만화 인트로**: 앱 시작 시 지훈이의 고민과 카페 방문 계기를 보여주는 스토리텔링 페이지 구현 (CSS 애니메이션 활용).
- **캐릭터 시트 시스템**: 수채화풍 캐릭터 '지훈'의 표정(무표정, 행복, 슬픔)을 하나의 시트 이미지에서 상황에 맞게 크로핑하여 노출.
- **영역 분리 레이아웃**: 대화 영역(상단)과 선택 영역(하단)을 시각적으로 분리하여 가독성 및 UX 개선.
- **포스트잇 선택지 UI**: 파스텔톤 메모지에 반투명 테이프 효과를 더해 입체적이고 귀여운 디자인 완성.
- **공감 로직**: 사용자의 답변에 따라 마음 온도가 실시간으로 변하고 배경색과 캐릭터 표정이 연동되는 시스템 구축.

## 3. 발생했던 문제 및 해결 (Solver)
- **에러**: 캐릭터 시트 연동 시 얼굴이 잘리고 몸통만 보이는 현상 발생.
  - **원인**: `background-size`와 `position` 설정이 1:1 이미지 비율에 최적화되지 않음.
  - **해결**: `transform: translate`와 `background-size: 100% auto`를 조합하여 얼굴 부위를 정확히 타겟팅함.
- **에러**: 코드 수정 중 HTML 마감 태그 누락으로 인한 앱 작동 중단.
  - **해결**: 파일 끝부분의 `startGame()` 함수와 마감 태그들을 전수 점검하여 복구 완료.

## 4. 향후 과제
- 시나리오 데이터베이스 확장 (더 다양한 갈등 상황 추가).
- 배경 음악(BGM) 및 효과음 추가를 통한 몰입감 증대.
- 대화 종료 후 결과 요약 및 공유 기능 구현.
