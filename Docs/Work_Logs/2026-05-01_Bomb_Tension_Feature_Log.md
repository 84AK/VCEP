# 시한폭탄 토크 앱 - 신규 기능 및 애니메이션 고도화 로그

**기록 일자**: 2026-05-01
**작성자**: Doc - 서기
**목적**: 시한폭탄 토크 앱(`offline_topic.html`) 내 '주제 변경 기능'과 '시간 경과에 따른 긴장감(Tension) 애니메이션' 추가 사항 기록

## 1. 신규 기능 구현 내역

### 1.1 폭탄 폭발 예외 처리된 '주제 변경' 기능
* **문제 상황**: 화면을 터치하면 무조건 폭탄이 터지게 설계되어 있어, 3분 내에 대화 주제가 일찍 끝났을 때 새로운 주제로 넘어갈 방법이 없었음.
* **해결 및 구현 (안전 지대 버튼 & 폰 흔들기)**:
  * **안전 지대 버튼 (Safe Button)**: 화면 중앙 주제 영역 아래에 `다른 주제로 넘어가기 🔄` 버튼을 추가. 자바스크립트의 이벤트 버블링 단계에서 `e.target.closest('#changeTopicBtn')` 조건을 통해 해당 버튼 터치 시에는 폭탄 폭발(`explode` 함수)이 일어나지 않고 새로운 주제만 뽑히도록 예외 처리 적용.
  * **기기 흔들기 (Device Motion)**: 웹 API인 `DeviceMotionEvent`를 활용하여 스마트폰의 가속도 센서를 감지. 사용자가 화면을 아예 만지지 않고 기기를 좌우로 가볍게 흔들기만 해도 주제가 무작위로 변경되도록 역동적인 센서 연동 기능 추가.

### 1.2 시간 경과에 따른 긴장감 고조(Tension) 애니메이션
* **요구 사항**: 시간이 점점 줄어들수록 폭탄이 터질 것 같은 시각/청각적 압박감이 필요함.
* **구현 내역**:
  * **1단계 (남은 시간 60초 미만)**: 폭탄의 박동(Pulse) 주기가 1초에서 0.5초로 빨라짐. 배경 화면에 은은하게 붉은빛이 감돌기 시작함 (`tension-1` 클래스 부여).
  * **2단계 (남은 시간 30초 미만)**: 배경의 붉은빛이 깜빡이기 시작하며, 폭탄이 위아래로 미세하게 흔들림(Shake) (`tension-2` 클래스 부여).
  * **3단계 (남은 시간 10초 미만)**: 극한의 긴장감. 배경화면 전체가 매우 빠른 속도로 붉게 점멸(`bgPulse 0.5s`)하고, 폭탄 컨테이너 주위에 강렬한 붉은 섀도우가 생성. 타이머 숫자의 크기가 커지면서 핏빛으로 붉어지고, 폭탄 텍스트 자체가 격렬하게 요동침(`bombShakeIntense`).
  * **Haptic Feedback (모바일 진동)**: 남은 시간 10초 미만 돌입 시 모바일 브라우저 환경에서 미세한 심장박동 진동(`navigator.vibrate(50)`)이 함께 울리도록 촉각 피드백 추가.

## 2. UI/UX 디자인 디테일
* **Glassmorphism 개선**: 새로 추가된 주제 변경 버튼 역시 투명도와 `backdrop-filter: blur(5px)`를 적용하여 전체적인 Glassmorphism 2.0 테마와 완벽하게 융화되도록 스타일링함.

## 3. 결과 및 향후 참고
* 사용자가 대화 중 어색함을 느끼지 않고 자연스럽게 다음 대화로 이어갈 수 있도록 편의성이 대폭 향상되었음.
* VibeCoding의 핵심인 '기기 센서 활용'과 '시각적 상호작용'을 동시에 만족하는 완성도 높은 앱으로 업그레이드 완료.
