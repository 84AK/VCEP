# 2026-05-01 스크린타임 기록기 (Time Thief Bounty) 업그레이드 기록

## 1. 기획 배경 (Blueprint)
* 단순히 텍스트를 입력하고 원형 차트를 보여주는 기존의 '스크린타임 기록기'는 사용자가 기록하는 행위 자체에 재미를 느끼기 어려웠음.
* 이를 해결하기 위해 내 시간을 훔쳐간 앱을 '현상수배범'으로 등록하여 수배 게시판에 붙이는 **'시간 도둑 현상수배'** 컨셉을 도입함.
* 8개 미니 앱 독립화 계획에 따라 **데이터 연동(GAS) 코드를 완전히 제거**하고 로컬 전용 앱으로 재설계함.

## 2. 디자인 변경 (UI Polish)
* **밝고 따뜻한 무드**: 사용자님의 요청에 따라 어두운 서부극 분위기가 아닌, 밝고 화사한 노란색 톤의 코르크 게시판(Bulletin Board) 스타일을 적용함.
* **글래스모피즘(Glassmorphism)**: 입력 패널에 반투명한 유리 질감을 적용하여 세련미를 더함.
* **수배 전단지(Poster) 디자인**: 
    * 사용자가 기록을 추가할 때마다 종이가 게시판에 쾅! 하고 붙는 애니메이션(`paperSlam`) 적용.
    * 전단지가 붙을 때 붉은색 'ARRESTED' 도장이 찍히는 효과(`stampHit`)와 햅틱 진동 피드백 결합.
    * 시간이 길수록 높은 등급(S-Class)의 붉은 테두리 전단지가 생성되어 시각적 경각심을 줌.

## 3. 핵심 기능 (Worker)
* **게이미피케이션 (Gamification) 강화**:
    * **도둑의 변명 (Thief's Excuse)**: 전단지를 클릭하면 몬스터가 얄미운 변명(예: "알고리즘이 시켰어요!")을 하는 말풍선 애니메이션 추가.
    * **검거 미션 (Arrest Mission)**: 도둑을 지우기 전, "물 한 잔 마시기", "눈 깜빡이기" 등 건강한 미션을 수행해야 체포할 수 있는 팝업 시스템 구현.
* **AI 캐릭터 활용 (Canvas 누끼)**: AI로 생성한 귀여운 '시간 도둑 몬스터' 이미지를 Canvas API로 실시간 누끼 처리하여 수배 전단지의 몽타주로 사용함.
* **Chunky UI 디자인**: 두꺼운 테두리(Border)와 강한 그림자(Drop Shadow)를 활용한 게임 버튼 스타일 적용.

## 4. 아키텍처 및 다음 단계 (Counselor)
* 모든 기록 및 삭제 기능은 로컬에서 즉시 이루어지며, 추후 '스마트폰 웰니스 마스터' 앱에서만 전체 데이터를 관리할 수 있도록 설계됨.
* 다음 단계로는 나머지 미니 앱들을 동일한 프리미엄 가이드라인에 맞춰 수정할 예정.
