# 양 떼 목장 앱 - AI 스프라이트 캐릭터 시트 적용 로그

**기록 일자**: 2026-05-01
**작성자**: Doc - 서기
**목적**: 밋밋했던 텍스트 이모지(🐑) 대신 AI 이미지 생성으로 만든 '걷는 양 스프라이트 시트(Sprite Sheet)'를 적용한 내역 기록.

## 1. 스프라이트 애니메이션(Sprite Animation) 적용
* **이미지 생성**: AI 이미지 툴을 사용하여 가로로 4프레임이 일렬로 배치된 `sheep_sprite.png` 캐릭터 시트를 생성함. (투명한 처리가 완벽하지 않으나, 2026년식 혼합 모드로 해결)
* **CSS `steps()` 기법 활용**: 
  * `background-size: 400% 400%;` (정사각형 원본 이미지의 비율과 4프레임에 맞춰 크기 보정)
  * `background-position-x` 속성을 `0%`에서 `133.333%`까지 `steps(4)`로 애니메이션 시켜, 양이 다리를 구르며 자연스럽게 걷는 4프레임 걷기(Walk Cycle) 애니메이션 구현 완료.

## 2. 자연스러운 합성(Blend Mode) 처리
* 생성된 이미지의 검푸른 배경색을 화면의 밤하늘 색상과 자연스럽게 녹이기 위해 `mix-blend-mode: screen;` 속성을 적용함. 
* 그림자(`drop-shadow`)를 추가하여 양이 평면적이지 않고 입체적으로 보이도록 시각적 완성도(UI Polish)를 높임.

## 3. 인터랙티브 페널티(놀라기 모드) 연동
* 폰을 터치하여 양이 깜짝 놀랐을 때, 다리가 보이지 않을 정도로 빠르게 걷는 느낌을 내기 위해 `.sheep-sprite.panic` 클래스를 추가.
* 놀랐을 때는 `walkSprite` 애니메이션 속도를 `0.6s`에서 `0.2s`로 3배 빠르게 적용하고, 그림자 색상을 붉은색으로 변경하여 패닉(Panic) 상태를 시각적으로 강조함.

## 3. 동적 배경 투명화(누끼) 처리 (Canvas API)
* **문제 발생**: AI가 생성한 이미지의 파란색 배경 때문에 `mix-blend-mode: screen`을 사용하더라도 양 주변에 네모난 박스가 희미하게 보이고, 그림자(`drop-shadow`)가 박스 테두리에 생기는 문제 발생.
* **해결 (Canvas API)**: 자바스크립트의 `Canvas API`를 활용하여 이미지가 로드될 때 실시간으로 픽셀 데이터를 분석함.
  * 픽셀의 RGB 값을 계산하여 `Blue` 채널이 우세한 픽셀(배경)의 `Alpha`(투명도) 값을 0으로 변경해 완벽한 투명 이미지(Base64 URL)로 변환.
  * 투명화된 이미지를 CSS 변수(`--sheep-bg`)로 덮어씌워 네모 박스를 완벽하게 제거하고 그림자가 양의 형태에 맞게 예쁘게 떨어지도록 고도화 완료.

## 결과
* 단순한 이모지를 넘어 진짜 게임 캐릭터처럼 걷는 모션이 추가되어 웰니스 앱의 감성적인 완성도와 몰입감이 극대화됨.
* 외부 이미지 편집 프로그램 없이 브라우저 단에서 AI 이미지의 찌꺼기 배경을 실시간으로 날려버리는 고급 프론트엔드 최적화 기법 적용 완료.
