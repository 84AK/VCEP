# VCEP 프로젝트 작업 로그 (Work Log)
- **날짜**: 2026년 5월 4일
- **작업자**: Antigravity (서기)

## 1. 작업 개요 (Overview)
VCEP 플랫폼의 브랜드 일관성을 확보하기 위해 전역 네비게이션 바(GNB)를 표준화하고, AI 타로 앱 및 시뮬레이션 페이지의 시각적 결함을 수정함.

## 2. 주요 수정 및 구현 사항 (Implementation Details)

### 2.1 GNB(Global Navigation Bar) 표준화
- **표준 사양**: 배경 `white`, 하단 테두리 `#E0E0E0`, 텍스트 `#3C4043`, 강조색(Active/Button) `#0F9D58`.
- **좌측 타이틀**: 모든 페이지 "바이브코딩 시뮬레이션"으로 통일.
- **메뉴 한글화**: [홈 / 시뮬레이션 / GAS / 앱 플래너 / 학습 가이드]로 메뉴 명칭 통일.
- **적용 파일**:
  - `index.html` (루트)
  - `apps/03_expert/vibecoding.html`
  - `apps/app_planner.html`
  - `apps/tutorial_hub.html`
  - `apps/04_gas_crud/gas_hub.html`
  - `apps/04_gas_crud/ai_tarot.html`
  - `apps/04_gas_crud/pixel_wall.html`

### 2.2 아고의 코딩 운세 (Argo) 고도화
- **명칭 및 테마 변경**: "타로왕 아고의 상담소"에서 **"아고의 코딩 운세"**로 변경하여 앱의 정체성을 담백하고 솔직하게 표현.
- **인트로 및 대사 최적화**: "코딩 데이터 운세"라는 표현을 도입하고, 질문 입력란에 코딩 관련 예시 문구 적용.
- **이미지 최적화**: 아고 캐릭터의 배경을 제거한 투명 PNG(`argo_character.png`) 적용 및 모든 리소스에 캐시 버스터(`?v=3`)를 추가하여 로딩 안정성 확보.
- **이미지 로딩 실패 대응**: `onerror` 핸들러를 추가하여 리소스 부재 시 대체 아이콘을 노출하는 예외 처리 구현.

### 2.3 시뮬레이션 페이지 UI 수정
- **버튼 복구**: `vibecoding.html`에서 스타일 충돌로 보이지 않던 '학습 가이드' 버튼을 `!important` 속성을 사용하여 강제 노출.
- **타이틀 정규화**: `<title>` 태그와 GNB 좌측 로고 명칭을 "바이브코딩 시뮬레이션"으로 일치시킴.

### 2.4 GAS CRUD 연동 표준화 (Standardization)
- **표준 서버 코드 v2 배포**: JSON 응답 구조를 표준화하고 예외 처리가 강화된 `GAS_SERVER_CODE.js (v2)` 배포.
- **가이드 모달 동기화**: `gas_hub.html`의 GAS 탭이 `GAS_SERVER_CODE.js` 파일을 실시간 fetch하여 최신 가이드를 제공하도록 로직 수정.
- **응답 해석 유연화**: 프론트엔드에서 서버 응답의 대소문자 및 형식을 유연하게 검사하여 저장 성공 여부 판별 정확도 향상.
### 2.5 프롬프트 엔지니어링 게임 (Mission 2) 개발

## 3. 발생한 문제 및 해결 방법 (Troubleshooting)

### 3.1 `app_planner.html` 구조 결함
- **문제**: 파일 내부에 `</head>`, `<body>` 태그가 중복 선언되어 스타일이 파편화됨.
- **해결**: 중복 태그를 정리하고 GNB를 `body` 최상단에 배치하여 스타일 레이아웃을 정상화함.

### 3.2 이미지 투명도 이슈
- **문제**: 배경이 흰색인 캐릭터 이미지가 다크 모드 배경에서 이질감을 줌.
- **해결**: Python `Pillow` 라이브러리를 사용하여 흰색 픽셀을 알파 채널로 변환하여 완벽한 투명 이미지 생성.
- **이미지 경로 오류**: 특정 화면에서 구형 파일명을 참조하여 이미지가 깨지는 현상 발견 후 `./argo_character.png`로 표준화함.
