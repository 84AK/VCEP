# 프로젝트 작업 로그 (Project Work Log)
**날짜:** 2026년 5월 12일
**작성자:** 서기님 (Scribe)

## 1. 작업 개요
VibeCoding 시뮬레이션 허브(`vibecoding.html`)의 시각적 완성도를 높이고, 프롬프트 실습 앱(`prompt_practice.html`)의 안정성을 강화하는 작업을 수행했습니다.

## 2. 세부 작업 내용

### 2.1 VibeCoding 허브 (`vibecoding.html`) 시각적 보정 및 최적화
- **버튼 텍스트 정렬 수정:** '전체 가이드북 열기' 버튼의 텍스트가 줄바꿈되던 현상을 `white-space: nowrap` 및 `max-width` 제거를 통해 해결했습니다.
- **캐릭터 스프라이트 이슈 해결:** 브라우저 환경에 따라 캐릭터 스프라이트가 비정상적으로 렌더링되거나 잔상이 남는 문제를 해결하기 위해 정밀 좌표 보정을 시도했습니다.
- **최종 디자인 결정:** 사용자의 요청에 따라 페이지 내의 모든 장식용 캐릭터 스프라이트를 제거하여, 핵심 콘텐츠(시뮬레이션 카드 및 텍스트)에 집중할 수 있는 깔끔한 레이아웃으로 최적화했습니다.

### 2.2 프롬프트 실습 앱 (`prompt_practice.html`) 안정성 강화
- **버튼 중복 클릭 방지:** 모든 스테이지 제출 버튼(`submitStage1~5`)에 `disabled` 로직을 추가하여 프롬프트 전송 시 중복 클릭으로 인한 중복 로직 실행을 차단했습니다.
- **애정 점수 중복 감점 방지:** 유효성 검사 실패 시 대화가 출력되는 동안 버튼을 비활성화 상태로 유지하고, 대화가 끝난 후에만 활성화하도록 수정하여 반복 클릭으로 인한 연속 감점 문제를 해결했습니다.
- **애정 점수 중복 합산 방지:** 퀴즈 옵션 버튼 및 시나리오 선택지 버튼 클릭 시 즉시 모든 인터랙션을 차단(`pointer-events: none`)하여 애정 점수가 여러 번 올라가는 버그를 근본적으로 해결했습니다.
- **대화 종료 가이드 노출 개선:** 마지막 대화 타이핑이 끝난 후 '클릭하여 계속' 안내가 나오지 않아 멈춘 것처럼 보이던 현상을 해결하기 위해, 콜백 유무와 관계없이 안내 가이드를 상시 노출하도록 수정했습니다.
- **입력창 조작성 개선:** 대화의 마지막 문장이 출력되면 즉시 패널 잠금(`locked-panel`)을 해제하여, 사용자가 안내 문구를 보면서 동시에 입력을 수정할 수 있도록 사용성을 강화했습니다.
- **대화 멈춤 버그 수정:** 대화가 출력되는 도중 새로운 대화가 요청될 때 시스템이 멈추는(Typing Race Condition) 현상을 `playDialogue` 함수의 상태 초기화 로직 보강을 통해 해결했습니다.
- **예외 처리:** 유효성 검사 실패 시에는 버튼을 다시 활성화하여 사용자가 수정한 후 재시도할 수 있도록 처리했습니다.

## 3. 발생 이슈 및 해결 (Troubleshooting)
- **Issue:** 캐릭터 스프라이트 좌표 보정 후에도 일부 환경에서 픽셀 밀도 차이로 인한 정렬 어긋남 발생.
- **Solution:** 장식 요소를 과감히 제거하고 텍스트와 카드 디자인을 강화하여 시각적 안정성을 확보함.
- **Issue:** 대화 도중 버튼을 누르거나 연속적인 이벤트 발생 시 대화창이 멈추고 텍스트 출력이 중단되는 현상 발생.
- **Solution:** `playDialogue` 시작 시 기존 타이머를 확실히 해제하고 `isTyping` 상태를 초기화하도록 개선하여 대화 시스템의 안정성을 확보함.
- **Issue:** 마지막 대화 종료 후 '클릭하여 계속' 안내가 나오지 않아 사용자가 조작 불능 상태로 오해하는 현상 발생.
- **Solution:** `onTypingDone` 함수에서 마지막 대화일 경우 항상 가이드 문구를 표시하고 인터랙션을 유도하도록 수정함.
- **Issue:** 에러 메시지 대화가 출력되는 동안 입력창이 잠겨 있어 즉각적인 수정이 불편한 현상 발생.
- **Solution:** 마지막 대화 타이핑이 끝나는 즉시 패널 잠금을 해제하여 사용자가 피드백을 확인하며 바로 수정할 수 있도록 개선함.
- **Issue:** 유효성 검사 실패 시 버튼이 즉시 활성화되어, 대화 도중 반복 클릭으로 인해 애정 점수가 계속 깎이는 현상 발생.
- **Solution:** `playDialogue`의 콜백 함수를 활용하여 대화가 완전히 종료된 시점에만 버튼을 다시 활성화하도록 로직을 변경함.
