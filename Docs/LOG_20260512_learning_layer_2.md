# 작업 로그: Learning Layer 2 — AI 응답 시뮬레이터 구현

- **날짜:** 2026-05-12
- **작업자:** 작업자(Worker) & 서기(Scribe)
- **대상 파일:** `apps/03_expert/prompt_detective.html`

## 🎯 작업 목표
프롬프트 엔지니어링의 핵심 기법(RCTF, Few-shot, Temperature, Negative, CoT)을 적용할 때 AI의 응답이 실시간으로 어떻게 변화하는지 보여주는 "실시간 분석기(AI Preview Panel)" 구현.

## 🛠️ 구현 내용

### 1. UI/UX 강화
- **AI 탐정 실시간 분석기 패널 신설:** 액션 패널 하단에 터미널 스타일의 분석창 추가.
- **시각적 효과:** 
  - `ANALYZING...` 상태 표시 및 맥동(pulse) 애니메이션 적용.
  - 타이핑 커서 및 실시간 텍스트 출력 효과로 AI의 사고 과정 연출.
  - `DEFAULT` vs `OPTIMIZED` 상태를 알리는 배지 시스템 도입.

### 2. 실시간 시뮬레이션 로직 (`updateAIPreview`)
- **Stage 1 (RCTF):** Role 입력 유무에 따른 말투의 전문성 변화 시뮬레이션.
- **Stage 2 (Few-shot):** 3개의 단서가 모두 채워졌을 때 단순 추측에서 증거 기반 패턴 매칭으로 답변 고도화.
- **Stage 3 (Temperature):** 슬라이더 값에 따라 '논리적/엄격함'과 '직관적/창의적' 말투 실시간 전환.
- **Stage 4 (Negative):** 편향 필터 적용 시 선입견이 배제된 객관적 분석 결과 노출.
- **Stage 5 (CoT):** 단계적 추론 과정이 포함된 최종 보고서 형식 시뮬레이션.

### 3. 데이터 구조화
- `AI_SIM_DATA` 객체를 통해 스테이지별 최적화된 샘플 텍스트를 관리하여 별도의 API 호출 없이도 빠른 반응성 확보.

## 🔍 해결 및 보완 사항
- **실시간 반응성:** `oninput` 이벤트를 통해 사용자가 타이핑하는 즉시 AI의 반응이 업데이트되도록 최적화.
- **UX 일관성:** 기존의 칩(Suggestion Chip) 선택 시에도 미리보기가 즉시 갱신되도록 로직 통합.
