## 🚀 구현 상세
### 1. 기능 우선순위(Tag) 선택 기능
- **기존**: 기능 추가 시 고정된 순서로 태그가 할당됨.
- **수정**: 각 기능 아이템의 태그를 클릭하면 `Must Have` -> `Should Have` -> `Nice to Have` 순으로 순환 선택할 수 있는 `togglePriority` 로직 구현.
- **효과**: 사용자가 기획 의도에 맞춰 중요도를 자유롭게 설정 가능.

### 2. 드래그 앤 드롭 순서 변경
- **라이브러리**: `SortableJS` (CDN) 도입.
- **UI 개선**: 아이템 왼쪽에 `fas fa-grip-vertical` 핸들을 추가하여 드래그 가능함을 시각화.
- **애니메이션**: 드래그 시 `ghostClass`를 적용하여 반투명 효과 및 부드러운 위치 교환 적용.

### 3. 데이터 영속성 (Auto-Save)
- **수정**: `saveDraft` 함수에서 DOM의 현재 순서와 각 아이템의 `data-priority` 값을 정확히 읽어오도록 개선.
- **복원**: `loadDraft` 시 저장된 순서와 태그 상태를 그대로 재현하도록 `addFeature` 함수 구조 개편.

## 🐞 문제 해결 (Fix)
- **이슈**: 기존에는 `featureCount` 변수에 의존하여 태그가 결정되었으나, 삭제 및 추가가 빈번할 경우 의도치 않은 태그가 붙는 문제 발생.
- **해결**: 태그 상태를 DOM 데이터셋(`data-priority`)에 직접 귀속시키고, 클릭 이벤트를 통해 상태를 제어하도록 독립적인 구조로 변경함.

## 🎨 디자인 (UI Polish)
- 벤토 그리드 스타일과 어울리도록 드래그 시 아이템에 그림자와 대시보드 테두리 효과 추가.
- 삭제 버튼(×)에 호버 효과를 추가하여 실수로 삭제하는 것을 방지하고 시각적 피드백 강화.
