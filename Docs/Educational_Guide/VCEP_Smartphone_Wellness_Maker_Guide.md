# 📱 스마트폰 웰니스 메이커: 기획부터 개발까지 (Step-by-Step Guide)

단순히 AI에게 "앱 만들어줘"라고 말하는 것은 진정한 코딩이 아닙니다. 이 가이드는 **기획자(Architect)**의 관점에서 문제를 정의하고, **작업자(Worker)**의 관점에서 AI와 협업하여 실제 앱을 완성하는 '바이브 코딩'의 정수를 담고 있습니다.

---

## 🚀 전체 학습 흐름 (Vibe Coding Workflow)

1.  **[기획]** `app_planner.html`을 사용하여 아이디어 구체화 (5단계)
2.  **[분석]** 완성된 기획서를 전문가용 PRD(제품 요구 사양서)와 비교 분석
3.  **[개발]** Gemini에게 기획서를 전달하여 코드 생성 및 CodeCanvas 실행
4.  **[연동]** 마스터 앱의 클라우드(GAS) 시스템과 연결하여 데이터 저장

---

## 🛠️ Phase 1: 나만의 앱 기획하기 (Planning)

먼저, 머릿속의 막연한 아이디어를 설계도로 바꿔야 합니다.

1.  **도구 실행**: `apps/app_planner.html` 파일을 브라우저나 CodeCanvas에서 엽니다.
2.  **5단계 퀘스트 수행**:
    *   **Step 1 (문제 정의)**: 내가 스마트폰을 쓰며 느끼는 진짜 불편함은 무엇인가요?
    *   **Step 2 (사용자)**: 이 앱을 가장 필요로 하는 사람은 누구인가요? (민준이, 서연이 등 가상의 인물 설정)
    *   **Step 3 (기능 설계)**: 반드시 있어야 할 핵심 기능(Must Have) 1가지를 정하세요.
    *   **Step 4 (화면 구성)**: 사용자가 앱을 켜면 처음 보는 화면은 무엇인가요?
    *   **Step 5 (이름 짓기)**: 앱의 성격이 드러나는 멋진 이름을 지어주세요.
3.  **기획서 생성**: 마지막 단계에서 `기획서 완성하기` 버튼을 누르고, 출력하거나 텍스트로 복사해 둡니다.

---

## 🔍 Phase 2: 전문가의 시선으로 분석하기 (PRD Review)

내가 만든 기획서가 실제 서비스가 되려면 더 구체적인 사양이 필요합니다. 우리가 미리 작성해둔 **전문가용 PRD**를 참고하여 내 기획서를 업그레이드하세요.

*   **참고 경로**: `Docs/PRD/01_Smartphone_Overuse/` 폴더
*   **학습 포인트**:
    *   **데이터 구조**: 어떤 키(Key) 값으로 데이터를 저장하는가? (예: `vcep_thieves_v2`)
    *   **디자인 원칙**: 2026년 트렌드(Glassmorphism, Bento Grid 등)가 어떻게 반영되어 있는가?
    *   **사용자 흐름**: 버튼을 눌렀을 때 어떤 애니메이션이 일어나는가?

---

## 🤖 Phase 3: AI와 함께 개발하기 (Building with Gemini)

이제 준비된 기획서를 Gemini에게 전달하여 코드를 생성할 차례입니다.

### **추천 프롬프트 구조 (복사해서 사용하세요)**

> **[역할 부여]** 당신은 2026년 최신 웹 기술에 정통한 시니어 개발자입니다.
> 
> **[기획서 전달]** 제가 작성한 앱 기획서 내용입니다:
> (여기에 app_planner에서 만든 기획서 내용을 붙여넣으세요)
> 
> **[기술 요구사항]**
> 1. Vanilla JS와 고급스러운 CSS를 사용하여 단일 HTML 파일로 만들어줘.
> 2. `Docs/PRD/01_Smartphone_Overuse/` 폴더의 PRD 스타일(디자인 원칙, 데이터 저장 방식)을 참고해줘.
> 3. 데이터는 `localStorage`에 저장하되, 키 이름은 `vcep_[앱이름]`으로 해줘.
> 4. (중요) 마스터 앱과 연동될 수 있도록 `localStorage.setItem`을 호출할 때 부모 창에 `postMessage`를 보내는 기능을 포함해줘.
> 
> **[실행]** 이제 이 앱의 전체 코드를 작성해줘.

---

## 🔗 Phase 4: 마스터 앱에 내 앱 등록하기 (Integration)

앱이 완성되었다면, 친구들이 내가 만든 앱을 볼 수 있도록 마스터 앱에 등록합니다.

1.  **파일 저장**: 완성된 코드를 `apps/01_smartphone/` 폴더에 새 HTML 파일로 저장합니다.
2.  **마스터 앱 수정**: `smartphone_wellness_master.html` 파일을 엽니다.
3.  **앱 리스트 추가**: `apps` 배열이나 Bento Grid 섹션에 내 앱의 경로와 아이콘을 추가합니다.
4.  **클라우드 확인**: 구글 스프레드시트에 내 앱 이름으로 된 시트가 생기고 데이터가 쌓이는지 확인하세요!

- [ ] Gemini를 통해 생성된 코드가 CodeCanvas에서 오류 없이 실행되는가?
- [ ] 마스터 앱 대시보드에 내 앱이 정상적으로 표시되고 데이터가 동기화되는가?
