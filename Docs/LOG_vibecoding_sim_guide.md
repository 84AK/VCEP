# 작업 로그: 밤샘 개발 시뮬레이션 가이드 제작
**날짜:** 2026-05-05
**담당:** 서기(Doc) & 건축가(Architect) & 디자이너(UI Polish)

## 1. 작업 개요
- **목적:** 'AI 실전 시뮬레이터(VibeCoding Sim)' 게임의 트러블슈팅 과정을 설명하는 체험형 가이드 슬라이드 제작.
- **대상 파일:** 
    - `apps/03_expert/vibecoding_sim_guide.html` (신규 생성)
    - `apps/03_expert/vibecoding_sim.html` (수정 - 가이드 버튼 추가)
    - `apps/tutorial_hub.html` (수정 - 카드 추가)

## 2. 주요 구현 내용
### 2.1. 디자인 컨셉
- **IDE & Cyber Theme:** `vibecoding_sim.html`의 사이버 블루(`--accent: #4fc3f7`) 테마와 다크 모드 스타일을 100% 반영.
- **Bento Grid Layout:** 2026년 최신 웹 트렌드인 벤토 그리드 레이아웃을 통해 가시성 확보.
- **Tech Visuals:** 'Fira Code' 폰트와 코드 스니펫 효과를 사용하여 개발자 감성 강조.

### 2.2. 슬라이드 구성 (총 7개)
1. **Intro:** 에이든과 함께하는 실전 앱 개발 시뮬레이션 소개.
2. **Scenario:** 밤샘 개발 상황 및 인터페이스(채팅, 에디터, 프리뷰, 터미널) 설명.
3. **Troubleshooting 01 (UI):** 화면이 깨졌을 때 캡처 도구와 시각적 컨텍스트를 활용해 해결하는 법.
4. **Troubleshooting 02 (Logic):** JS 로직 오류 발생 시 터미널 로그를 분석하여 AI에게 지시하는 법.
5. **Strategy:** AI 인턴의 인내심 관리 및 구체적인 피드백 전략.
6. **Outcome:** 완성된 결과물 및 협업 점수 확인 프로세스.
7. **CTA:** 시뮬레이션 시작 버튼.

## 3. 핵심 수정 사항 (Refinement)
- **가독성 개선:** 마왕군 가이드 제작 시 얻은 피드백을 반영하여 본문 폰트 크기(`1.15rem`)와 줄 간격(`1.7`)을 시원하게 조정.
- **일관성 유지:** 게임 원본의 CSS 변수를 그대로 사용하여 게임과 가이드 간의 이동 시 이질감을 최소화함.

## 4. 향후 참고 사항
- 캡처 도구 설명 시 시각적 예시를 강화하기 위해 `viewfinder` 아이콘 사용.
- 전문가 과정(Expert Mission) 카드는 파란색 테마로 설정하여 마왕군 스타트업(빨간색/보라색)과 시각적으로 구분.
