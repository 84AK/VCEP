# Project Work Log: AI Dating Simulator (Melt the Iron-Wall AI)

## 📅 작성일: 2026년 5월 4일
## ✍️ 작성자: 서기 (Scribe)

### 1. 주요 구현 사항 (Implementation)
- **시행착오(Mistakes) 추적 시스템**: 각 스테이지별 제출 실패 횟수를 기록하고, 실패 시마다 호감도를 -5점 차감하는 교육적 패널티 로직 구현.
- **부정행위 감지(Anti-Cheat) 시스템**: 제공된 'Best Practice' 예시 문구를 그대로 복사하여 제출할 경우 감지하여 호감도 -20점 차감 및 최종 등급을 `F`로 고정.
- **동적 평가 등급 시스템**: 시도 횟수에 따라 **S(Master), A(Advanced), B(Stable), C(Normal)** 등급을 실시간 계산하여 엔딩 성적표에 표시.
- **UI/UX 개선**: 
    - 최종 엔딩 화면의 버튼 문구를 "홈 화면으로 이동"으로 변경하여 사용자 흐름 개선.
    - 성적표에 '총 시행착오 횟수' 및 '부정행위 경고' 섹션 추가.
- **보안 강화**: 모든 사용자 입력 필드에 `sanitizeHTML` 로직을 적용하여 XSS(Cross-Site Scripting) 공격 방어.

### 2. 수정 및 에러 해결 (Bug Fixes & Troubleshooting)
- **인코딩 오류 해결**: 파일 편집 과정에서 발생한 특수 문자(깨진 바이트)로 인한 charset 감지 오류를 `iconv` 명령어를 통해 UTF-8로 정화하여 해결.
- **함수 구조 중첩 오류 수정**: `switchStage` 함수 내부에 `submitStage1`이 잘못 삽입되었던 구조적 결함을 발견하고, 전체 파일 재작성(Rewrite)을 통해 완벽하게 복구.
- **애니메이션 타이밍 조정**: 엔딩 스크린 표시 시 `startTransition`과 `anime.js`의 실행 순서를 동기화하여 시각적 어색함 제거.
