# Monster Startup UX Improvement Log

## 작업 개요
- **일시:** 2026-05-07
- **작업자:** Antigravity (Fix/Worker/Scribe)
- **목적:** 학생들의 실습 편의성을 위해 전체적인 폰트 크기를 확대하고, 직접 입력창의 직관성을 개선함.

## 수정 사항

### 1. 폰트 크기 확대 (Readability)
- **전역 설정:** 기본 폰트 크기를 `16px`에서 `18px`로 상향 조정.
- **선택지 카드 (.option-card):** `0.9rem` -> `1.2rem`으로 확대하여 가독성 확보.
- **입력창 (input):** `0.8rem` -> `1.2rem`으로 확대.
- **워크스페이스 타이틀 및 설명:** 타이틀 `1.6rem`, 설명 `1.1rem`으로 확대.
- **대화창 (.dialogue-content):** AIDEN의 대화 텍스트 크기를 `1.2rem`으로 상향.
- **모달 (.modal-text):** 최종 승인 팝업의 텍스트 크기를 `1.2rem`으로 확대.
- **네비게이션 링크:** 모바일 `1.2rem`, 데스크탑 `1rem`으로 상향.

### 2. 입력창 직관성 개선 (UI/UX)
- **입력창 강조:** 모든 입력창에 `var(--monster-green)` 보더와 `box-shadow`를 추가하여 입력 가능한 영역임을 강조.
- **레이블 추가:** 단순 Placeholder 대신 `.input-label`을 사용하여 "SQUAD NAME", "APP NAME" 등을 명확히 표시.
- **직접 입력 섹션 분리:** 
    - `custom-input-box` 클래스를 신설하여 선택지와 시각적으로 분리함.
    - 빨간색 점선 보더와 "⌨️ DIRECT ENTRY" 아이콘/텍스트를 추가하여 "키보드 입력이 필요함"을 직관적으로 알림.
    - "입력창을 클릭하여 키보드로 내용을 작성하세요"라는 안내 문구 추가.

## 결과
- 학생들이 버튼형 선택지와 텍스트 입력창을 혼동하지 않고 명확하게 구분할 수 있게 됨.
- 작은 글씨로 인한 피로도를 줄이고 실습 몰입도를 높임.
