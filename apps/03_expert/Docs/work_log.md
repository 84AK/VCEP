- **요청 사항:** 스테이지 1에서 입력한 페르소나 프로필에 따라 이후 대화와 스토리가 진행되도록 개선
- **담당 역할:** 건축가(설계), 작업자(구현), 해결사(복구), 서기(기록)

## 🛠️ 구현 내용
### 1. 페르소나 응답 생성 엔진 (Stage 1)
- `generatePersonaResponse` 함수를 구현하여 사용자가 입력한 RCTF(Role, Context, Task, Format) 값을 바탕으로 AI의 가상 응답을 생성.
- 입력 직후 캐릭터가 해당 페르소나에 빙의하여 대화를 건네는 시퀀스 추가.

### 2. 동적 스토리 시스템 (Stage 2-4)
- `switchStage` 함수를 개선하여 사용자가 설정한 페르소나 명칭(`gameState.personality`)이 스토리 지문 및 캐릭터 대사에 자연스럽게 삽입되도록 수정.
- 예: "아까 네가 설정한 '[페르소나 명칭]' 정체성 말이야..." 등의 대사 구현.

### 3. 스테이지 2 동적 리액션 시스템 (Few-shot)
- 사용자가 입력한 예시 데이터에서 첫 번째 키워드를 추출하여 대사에 실시간 반영.
- 하드코딩된 대사("원목 스타일")를 제거하고 사용자 입력 기반의 맞춤형 피드백 제공.
- 퓨샷 데이터 유효성 검사 임계값을 40자에서 30자로 최적화.

### 4. 스테이지 4 금기어 분노 연출 (Drama)
- 스테이지 4 진입 시 캐릭터가 사용자의 특정 발언(아이리스: '데이터', 카일: '대충')에 분노하는 시나리오 추가.
- `setCharExpression('angry')` 호출 및 화면 점멸 효과를 통해 위기 상황 연출 강화.
- 부정 프롬프트(Negative Prompt)의 필요성을 스토리텔링으로 자연스럽게 유도.
