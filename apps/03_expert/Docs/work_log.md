## 🛠️ 2. 주요 에러 및 해결 기록 (Error Fix Log)

### ❌ 팝업창 불통 및 가려짐 문제
- **문제:** `z-index` 설정에도 불구하고 팝업창이 화면에 나타나지 않음.
- **원인:** 기존 레이어의 쌓임 맥락(Stacking Context) 문제로 인해 `z-index`가 무시됨.
- **해결:** `modal-wrap` 요소를 HTML `body`의 최상단 직계 자식으로 이동시키고, `display: flex !important`와 자바스크립트 직접 제어를 통해 가시성 확보.

### ❌ 클릭 반응성 저하 문제
- **문제:** 일반 `div` 태그로 만든 선택지가 클릭에 민감하게 반응하지 않음.
- **원인:** 브라우저 기본 인터랙션 한계 및 투명 레이어의 간섭.
- **해결:** 선택지를 의미론적으로 올바른 `<button>` 태그로 전환하고, `pointer-events` 속성을 정밀 제어하여 클릭 감도를 획기적으로 개선.

### ❌ 한글 텍스트 겹침 (Race Condition)
- **문제:** 이전 문장의 타이핑이 끝나기 전 다음 문장이 시작되어 글자가 섞임.
- **원인:** `setTimeout` 루프가 중첩되어 실행됨.
- **해결:** 전역 타이머 변수를 도입하여 새로운 텍스트 출력 시 기존 타이머를 즉시 중단(`clearTimeout`)하도록 처리.
