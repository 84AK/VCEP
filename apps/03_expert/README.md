## 🎮 Project Overview
본 프로젝트는 **'바이브코딩(Vibe Coding)'** 기법을 활용하여 앱 기획의 핵심 프로세스를 RPG 게임 형식으로 체험할 수 있는 교육용 시뮬레이터입니다.

### 🚀 Key Features
- **Immersive Narrative:** 8비트 RPG 감성의 스토리텔링과 애니메이션 효과.
- **Strategic Decision System:** 팀원 간의 합의를 유도하는 전략적 선택 팝업 시스템.
- **Planning Master Guide:** 페르소나, 페인 포인트, MVP 등 실전 기획 가이드 내장.
- **Automatic PRD Generation:** 시뮬레이션 종료 후 즉각적인 제품 요구 사양서(PRD) 및 Mermaid 다이어그램 생성.

## 🛠️ Technical Stack
- **Frontend:** HTML5, Vanilla CSS, Javascript (ES6+)
- **Libraries:** Font Awesome, Google Fonts, Mermaid.js
- **Design:** Pixel-art aesthetics with custom animation logic.

## 📁 Project Structure
- `monster_startup.html`: 메인 시뮬레이션 엔진 및 UI.
- `assets/`: 캐릭터 스프라이트, 배경음악 및 시각 자산.
- `Docs/work_log.md`: 개발 및 버그 수정 기록 로그.
