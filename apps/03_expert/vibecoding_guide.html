AI 협업 마스터 가이드

바이브코딩의 핵심은 '정확한 증거'와 '논리적 소통'입니다.

📸
시각적 증거 확보 (Capture)

언제 사용하나요? (Problem)

  • 버튼이나 텍스트가 화면 밖으로 잘려 보일 때
  • 이미지가 엑박으로 뜨거나 레이아웃이 깨졌을 때
  • 디자인이 기획서와 다르게 출력될 때

어떻게 해결하나요? (Solution)

에러가 발생한 지점을 드래그하여 캡처하고 AI에게 전달하세요. 캡처는 백마디 말보다 정확합니다.

"이 스크린샷을 봐줘. 하단 버튼이 반쯤 잘려서 클릭이 안 돼. CSS flex 설정을 확인해서 수정해줄래?"
📜
기록의 추적 (Log Analysis)

언제 사용하나요? (Problem)

  • 버튼을 눌러도 아무 반응이 없을 때
  • 데이터가 로딩되지 않고 무한 로딩에 빠졌을 때
  • 화면은 멀쩡한데 기능만 작동하지 않을 때

어떻게 해결하나요? (Solution)

개발자 도구(Console)를 열고 빨간색 **[Error]** 로그를 복사하세요. 에러의 '지문'을 찾는 과정입니다.

"콘솔에 'Uncaught ReferenceError: submitData is not defined'라는 에러가 떴어. 함수 선언부를 확인해서 고쳐줘."
🧩
논리 재조립 (Logic Rebuild)

언제 사용하나요? (Problem)

  • 코드의 앞뒤 순서가 바뀌어 엉뚱한 결과가 나올 때
  • 특정 조건을 만족했는데도 다음 단계로 안 넘어갈 때
  • 복잡한 계산 로직이 내 의도와 다르게 작동할 때

어떻게 해결하나요? (Solution)

생각하는 올바른 순서를 **단계별(Step-by-Step)**로 정리하여 AI에게 제시하세요.

"로직 순서를 이렇게 바꿔줘: 1. 데이터 검증 -> 2. 로컬 저장 -> 3. 서버 전송. 지금은 3번이 먼저 되고 있어서 에러가 나."
