🚀 기술 스택별 구현 가이드

React

Vite + Tailwind CSS 환경을 추천합니다. Framer Motion을 활용해 부드러운 화면 전환을 구현해보세요.

Python

Streamlit이나 PyScript를 사용하여 데이터 시각화 앱을 빠르게 프로토타이핑할 수 있습니다.

Native

React Native나 Flutter를 사용하여 실제 앱스토어 배포용 네이티브 앱을 설계해보세요.
